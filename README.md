# KageDesktopTool · Kage 桌面工具

把工作资料、常用快捷方式和待整理文件收进桌面上的 Folder，按需展开、随手拖放，让文件有自己的位置。

每个桌面 Folder 都对应一个真实文件夹。你可以直接在桌面查看、打开和整理内容，也可以随时在资源管理器中访问它们。

## 软件特色

- **在桌面上分类收纳**：创建多个 Folder，独立展开或折叠，头部显示名称和文件数。
- **拖放即可整理**：支持桌面、资源管理器和不同 Folder 之间的多文件拖放；同名文件可选择保留两份、跳过或取消。
- **自由安排布局**：拖动头部调整位置，松手后自动寻找附近空位，其他 Folder 保持原位；宽度、内容区高度和头部高度均可调整。
- **按习惯查看内容**：网格与列表随时切换，提供四档图标尺寸，可按名称、修改日期、大小或自定义顺序排列。
- **保留熟悉的 Windows 操作**：双击打开文件，右键显示原生传统文件菜单，支持 Ctrl／Shift 多选和框选。
- **每个 Folder 都有自己的样式**：独立设置背景颜色与透明度，实时预览；另有四套应用／托盘图标方案可选。
- **保存布局与操作结果**：重启恢复布局和偏好，文件操作结果可从通知查看；支持开机自启、整体存储目录迁移和中断恢复。

## 安装与首次使用

当前版本为 **1.1.0**，适用于 **Windows x64**。完整发布包为 `KageDesktopTool-win-x64-1.1.0.zip`，自带所需运行环境，无需另外安装 .NET。

目前 GitHub 仓库提供源码，尚未上传可直接运行的发布附件。已有完整发布包时，按以下步骤使用：

1. 将整个 ZIP 解压到固定目录，例如 `D:\工具\KageDesktopTool\`，保留包内全部文件。
2. 双击 `KageDesktopTool.exe`，在系统托盘找到程序图标。
3. 右键托盘图标，打开“设置 → 存储”，确认文件存放位置。默认是 `D:\KageFiles\`；该位置不可用时，请选择其他可用目录。
4. 从托盘选择“新建 Folder”，或按 **Ctrl+Alt+K**，输入分类名称。
5. 将桌面或资源管理器中的文件拖到 Folder，点击头部右侧按钮展开，即可查看和使用。

首次运行的工具没有 Folder，可按自己的习惯创建“工作”“常用”“待整理”等分类。

## 日常操作

| 想做什么 | 操作方法 |
| --- | --- |
| 新建分类 | 托盘右键“新建 Folder”，或按 `Ctrl+Alt+K` |
| 展开／折叠 | 点击 Folder 头部右侧按钮，多个 Folder 可同时展开 |
| 打开文件或子文件夹 | 双击图标或文件名 |
| 选择多个项目 | 使用 Ctrl／Shift 点击，或从空白处拖动框选 |
| 调整显示与排序 | 在内容区的“查看”菜单中选择网格／列表、图标尺寸和排序方式 |
| 手动排列项目 | 在同一 Folder 内拖动到插入位置，自动切换为自定义排序 |
| 移动或调整 Folder 大小 | 拖动头部移动；拖动右下角调整大小；展开后拖动头身分隔线调整头部高度 |
| 修改样式或名称 | 右键头部，选择“样式…”或“重命名…” |
| 查看文件操作结果 | 点击 Windows 通知，或打开“设置 → 通知” |
| 退出程序 | 托盘右键“退出”；关闭设置窗口后程序仍在运行 |

### 文件移动与删除

跨 Folder、桌面或资源管理器拖放会**实际移动文件**，原存放位置随之改变；拖动快捷方式只移动快捷方式文件本身。同一 Folder 内的手动排序只改变展示顺序。

删除 Folder 时可选择：

- **保留内容**：移除桌面上的 Folder 入口，保留真实内容，并在桌面生成指向内容文件夹的快捷方式。
- **一同删除**：将整个内容文件夹及其中的文件移入回收站。

从 Folder 拖出到桌面时，图标会放到释放位置附近。若想保留自行选择的位置，请在桌面右键“查看”中关闭“自动排列图标”。

### 设置、自启与升级

“设置”包含通用、桌面 Folder、存储、通知、恢复与状态、关于六个分区。开启或关闭自启后，点击“应用自启选择”；消息提示开关需点击“保存消息提示选择”。关闭消息提示后，仍可在“通知”中查看操作详情。

需要更换文件存储位置时，在“存储”中选择新目录，点击“迁移并保存目录”，由工具迁移已有内容并更新关联快捷方式。遇到中断或目录暂不可用，可在“恢复与状态”查看实际路径和处理入口。

升级或移动程序位置前，从托盘退出程序，备份设置和重要文件，再将整个新包解压到最终目录。启动后检查已有 Folder，并重新应用自启选择。详细步骤见[完整使用说明](docs/使用说明.md)。

## 文件与设置存放在哪里

- **文件内容**：位于你在“设置 → 存储”中选择的根目录下，每个 Folder 对应一个同名文件夹。
- **布局和偏好**：保存在 `%LOCALAPPDATA%\KageDesktopTool\`，独立于程序安装目录。备份时请同时保留重要内容和该设置目录。

当前发布版已在 Windows 11 x64、单屏 150% 缩放环境验证；实际多屏与混合 DPI 环境尚待验证。
