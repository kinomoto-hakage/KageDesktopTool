# Kage 桌面工具 1.1.3

- 新增逐 Folder 实时毛玻璃背景，文字与图标保持清晰；可独立开启或关闭。
- 模糊强度支持 0–100%，默认 50%；支持键盘微调、悬浮说明和恢复默认，与其他样式一起预览、应用、取消并在重启后恢复。
- 系统透明效果、高对比度、省电及桌面环境限制下显示原因并保留设置，条件恢复后自动恢复效果。
- 保留四向头部、文件整理、原生菜单、多选、拖放及已有状态兼容；完善真实桌面输入、捕获和恢复检查。
- 整理仓库，移除历史票据、验收副本和旧开发包，本地与远程分支统一到 `main`。

下载 `KageDesktopTool-win-x64-1.1.3.zip`，完整解压后双击 `KageDesktopTool.exe`。发布包包含运行环境，无需另装 .NET。更新前先从托盘退出旧版，并备份设置与重要文件；不要只替换 EXE。校验文件为同名 `.zip.sha256`，包内附逐文件 `SHA256SUMS.txt`。

验证环境为 Windows 11 x64、单屏 150% 缩放。本次打包校验、30 项隔离业务检查、核心毛玻璃交互与普通启动通过；两项桌面交互检查未通过，完整桌面分组未全量完成，详细结果见 [1.1.3 发布验收记录](https://github.com/kinomoto-hakage/KageDesktopTool/blob/v1.1.3/docs/verification/release-1.1.3.md)。其他 Windows、真实多屏、混合 DPI、HDR 及第三方动态壁纸的全部宿主方式尚未实测。
