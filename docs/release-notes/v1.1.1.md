# Kage 桌面工具 V1.1.1

Windows x64 自包含版，解压整个 ZIP 后双击 `KageDesktopTool.exe`，无需另外安装 .NET。

本版包含：

- 网格四档尺寸与三行名称省略；选中长名称可展开全文并滚动到末尾。
- 统一 Folder、桌面及应用切换时的选择清除，保留当前多选、滚动和文件拖动行为。
- 四向头部与横排／竖排名称；样式窗口按方位显示头部高度／宽度及滑块数值。
- 修复未应用样式期间的周期闪烁，以及下侧／右侧分隔线拖动方向。
- 尺寸、展开、方向切换和样式滑块受阻时保持有效布局；只有拖动位置松手时寻找附近空位。
- `.url` 与 `.lnk` 快捷方式隐藏显示后缀；改名时保留实际扩展名、目标和图标。

升级前从旧程序托盘选择“退出”，备份设置和重要内容，再将整个新包解压到固定目录。新版本保留现有 Folder、真实内容目录、布局和偏好；启用了开机自启时，请在新包设置中重新应用自启选择。

76 项业务回归、发布包运行时／图标及逐文件 SHA256、最终包真实输入、窗口重建和普通启动验收通过；用户人工复查通过。实际硬件覆盖单屏 150%，实际多屏与混合 DPI 尚未验证。

附件提供完整 ZIP 和相邻 SHA256 文件。
