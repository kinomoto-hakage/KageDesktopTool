# 10 中断迁移恢复与实际内容定位验收

验收日期：2026-10-03。对应 [任务 10](../../.scratch/desktop-folder/issues/10-recover-interrupted-migration.md)。

## 用户入口与恢复规则

重启发现 `PendingRootMigration` 后先只读核对每项原位置、迁移位置、稳定标识及工具快捷方式的实际目标。读取快捷方式目标不依赖目标目录仍在原位置，能够识别目录已经迁移、链接尚未更新的中断。启动不重复执行迁移，不直接套用旧／新全局根目录，也不改写未完成记录。已经最终提交新配置的迁移按新配置正常打开。

设置显示活动及保留内容的未恢复清单、两边真实路径、归属核对状态和实际快捷方式目标。存在的原／迁移位置各有打开按钮，经 Windows Explorer 定位。没有可确认归属的位置时暂停该 Folder 的正常展示与枚举。恢复期间停用更换根目录入口，业务 interface 同时暂停创建、改名、删除、文件移动及其他修改。

“重试恢复旧位置及快捷方式”通过共用 `IDesktopWorkspace.RecoverRootMigrationAsync` 执行，显示独立进度／结果窗口。恢复与其他修改共用独占次序，在后台核对并逆序恢复每项；已经恢复的内容不重新移动，只确认必要状态。全部原目录及链接核对正确、最终旧配置成功保存后才解除恢复状态。保留目录不会重新出现为活动入口，稳定标识、位置、尺寸、展开、查看方式和外观记录保持不变。

## 中断及安全边界

恢复以实际文件状态为依据，不依赖阶段记录已及时更新。不同字节、其他归属、不可确认的路径或快捷方式不覆盖；失败时保留逐项阶段、错误、两边路径及仍可定位的文件。目录已恢复而最终配置提交失败时，仍保留日志及恢复状态，下一次重试只补核对和提交。

规格审查提示目录创建后、标识写入前的内部中断窗口。先通过真实子进程退出复现，再补充恢复规则：仅在 `Moving`／`Restoring`／`RecoveryRequired` 阶段、另一边归属已确认时，允许处理没有条目且没有 NTFS 命名流的空目录；未知标识、非空目录及命名流均保留。目录传输共用 `CopyIdentityFirst`，在复制目录命名流和用户内容前先持久复制归属标识；清理内容时最后才移除标识。

不可确认的非空内容及外部修改仍需用户核对，程序保留证据和定位入口，不自动合并未知目录或重写外部快捷方式。

## 业务与进程检查

新增五组公共 interface 检查，使用随机真实临时目录、实际 `.lnk`、嵌套文件及 NTFS 命名流。指定故障只注入目录传输／状态保存边界，断开链接目标通过真实 Windows Shell 读取。检查执行前重启、陈旧阶段与实际路径、逐项恢复失败、最终提交失败后重新打开、重复恢复、同名不同字节、其他归属及无条目但有目录命名流的保留行为。

进程检查启动独立检查子进程，在持久日志或指定实际文件效果后以退出码 73 终止，绕过当场异常回滚；父进程重新打开相同工作区，通过正式 interface 定位及重试恢复。对目录部分复制、创建和清理窄窗口使用指定传输适配器构造对应真实磁盘状态后退出。十二个阶段分别为：

| 阶段 | 重新打开后的预期 |
| --- | --- |
| 执行前 | 核对原内容，无额外复制 |
| 目标创建后 | 仅安全处理无内容、无命名流的空目标 |
| 目录部分复制 | 核对两边内容，恢复后清理已验证副本 |
| 目录移除后 | 根据目标归属定位，恢复旧位置 |
| 源清理末尾 | 核对目标后处理源空目录并恢复 |
| 链接更新前 | 识别断开的旧目标并恢复内容 |
| 链接更新后 | 恢复真实旧目录和链接目标 |
| 配置提交前 | 保持旧配置，恢复全部内容 |
| 配置提交后 | 正常加载已提交新配置，不回滚 |
| 恢复创建后 | 处理无内容、无命名流的源空目录并继续恢复 |
| 恢复移除后 | 核对已恢复目录，继续链接及配置提交 |
| 恢复清理末尾 | 核对原归属后处理目标空目录并提交 |

每个阶段核对文件字节、嵌套内容、命名流、旧／新实际路径、稳定记录、保留链接目标及另一边无残留副本，并再次启动／重试验证无额外文件效果。启动只读通过检查主状态文件字节不变确认。
