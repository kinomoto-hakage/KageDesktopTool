# Windows 验证流程改进验收

2026-10-16，落实毛玻璃实现复盘中的六项改进。操作入口与恢复规则见 [Windows 验证与交接](../agents/windows-verification.md)。

## 交付内容

| 改进 | 实现 |
| --- | --- |
| 既有检查接入自动约束 | `checks.json` 为统一清单，构建／发布复制随包；仓库检查核对全部 CLI 入口；GitHub Windows CI 和本地 `verify-ci.ps1` 共用入口 |
| 稳定桌面夹具 | `DesktopCheckSession` 共用输入稳定、实际 HWND 命中、无遮挡截图、屏幕像素、隔离布局和恢复栈；捕获与组合检查已接入；其他检查的证据目录统一接入 |
| 中断检查点 | 每次运行独立 JSON，记录提交、完整包摘要、命令、进程身份、退出状态和剩余计划；超时保留恢复进程，恢复保留旧尝试并跳过成功项 |
| 稳定人工检查包 | 主工作区的唯一完整目录、独立构建、逐文件摘要、明确 EXE 与提交、`latest.json`；退出旧实例的提示随包提供 |
| 临时日志自动约束 | 正式代码中的 `.scratch` 和直接 `File.Append*` 使仓库检查失败；检查源码／专用证据模块可写诊断，正常业务状态写入可通过 |
| 精简交接与导航 | `AGENTS.md` 按需指向 Windows 文档；文档提供检查点恢复、精简交接字段和桌面模块导航 |

- 仓库约束：36 项检查、38 个 CLI 入口登记一致，PowerShell 语法检查通过。

- 独立 Release 构建：0 警告、0 错误。
- 执行器契约：遗漏入口和临时诊断会失败；正常状态写入可通过；含空格路径、超时保留进程、防重入、原计划恢复、成功项去重、重试证据隔离、PID 身份以及包内 DLL 改变拒绝恢复均通过。

## 覆盖边界

上述桌面结果来自当前单屏 2560×1600、150% Windows 会话，不能推导出硬件多屏、混合 DPI 或其他机器上的实测结论。GitHub CI 配置已加入仓库；本文的 CI 结果指本机运行相同入口，不代表已经取得远端 Actions 结果。

会话互斥覆盖存活的执行器；中断后仍运行的子进程由原工作树的运行记录核对。其他工作树遗留进程需要回到其原记录恢复。所有检查都能从清单查询，但本轮没有重跑与夹具改动无关的完整发布回归。
