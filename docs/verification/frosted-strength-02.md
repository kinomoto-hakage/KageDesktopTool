## 行为与输入

正式样式窗口的滑块已有整数步进 1、大步进 10 与 WPF 的焦点内键盘操作。本票保留这些标准行为，通过真实系统键盘验证 Tab 聚焦、四个方向键、Page Up／Down、Home／End、重复按键以及 0／100 两端的限制。焦点仍在颜色输入框时，方向键不会修改强度。

滑块增加完整中文悬浮说明。实际鼠标悬停打开可见 ToolTip，截图显示全文换行且没有裁切；悬停后颜色输入框仍持有键盘焦点。提示文字为：“单击滑块或按 Tab 将焦点移到滑块后：方向键调整 1%，Page Up／Down 调整 10%，Home 调至 0%，End 调至 100%。”

“恢复默认”仅把同一滑块设为 50%，经已有 `ValueChanged`、`AppearanceInteraction.SetFrostedStrength` 与预览入口生效。它与滑块都只按用户的毛玻璃开关统一置灰；完全不透明、零强度不会使操作不可用。按钮没有独立保存路径，也没有重置颜色、透明度或其他样式。

真实桌面检查 `--frosted-strength-controls-check` 使用隔离 JSON 工作区，全部点击前经 `DesktopCheckSession.InputPointAsync` 的样式窗口重载等待实际 HWND 命中稳定。系统鼠标和键盘执行输入；检查观察有效 Folder、完整正式记录、真实 JSON、只读百分比、另一 Folder 和重启结果。没有调用控件事件或给强度控件直接赋值来代替输入。可见提示通过实际 Popup 的可见文本确认，并保存完整屏幕 PNG。
