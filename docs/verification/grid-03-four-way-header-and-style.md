# 03：Folder 四向头部、名称方向与样式事务

对应票据：[03-four-way-header-and-style](../../.scratch/folder-grid-selection-and-header/issues/03-four-way-header-and-style.md)。实施前基线：`59722219ae3caf80d9f5f1a4446980c6afb0adb9`。

## 实现

- `FolderRecord` 新增头部位置、名称方向及独立侧栏宽度；缺字段的旧配置默认上方、横排、侧栏 96 DIP。既有 `HeaderWidth` 继续表示展示宽度，`BodyHeight` 表示展示高度，上／下厚度保留 `HeaderHeight`（42–82 DIP），侧栏宽度采用独立的 64–360 DIP 范围。
- `FolderGeometry` 统一物理窗口边界。`X/Y` 始终表示头部左上角，下／右头部展开时窗口原点向上／左偏移。显示器选择、工作区并集与屏幕空洞、碰撞、最近空位、拖动和 HWND 定位共用这一关系。
- 上／下／左／右分别向下／上／右／左展开。切换方向保留展示宽高、图标和内容文字方向；侧栏名称在上、横排文件数在下、按钮在底端。名称按 Unicode 用户可见字符竖排，保留组合字符，空间不足省略，悬停显示完整名称。
- 展开时分隔线调整相应方向的头部厚度；远端外角调整展示宽高。折叠时右下角调整长度与厚度，长度同步相接展示边长。实际鼠标按目标 DPI 换算，拖动预览可穿过其他 Folder，释放后只寻找当前 Folder 的合法落点。
- 外观会话以单一有效 `Draft` 保存方向、名称、侧栏宽度、颜色、透明度与预览挪位。预览不写正式状态，空间不足保留最后有效草稿，应用一次保存，取消连挪位一起恢复。保存失败保留草稿供重试；显示环境、后来的样式或相关几何变化使旧会话失效。仅颜色／名称修改仍保留后来独立提交的非样式字段。
- 样式正文可滚动，底部应用／取消按钮固定可见，窗口高度受工作区限制。

## 验证边界与方法

沿用规格已批准的 `IDesktopWorkspace` 业务边界和真实 Windows 输入；随机隔离工作区使用真实目录、文件、快捷方式与原子状态保存。业务测试按 `tdd` 从四向锚点、独立尺寸逐步扩展到草稿事务及恢复；不引入测试专用业务 API。

新增 7 组业务检查覆盖八组合的几何基础、展开／折叠、分隔线和外角、折叠长度同步、无空间、有效草稿、保存失败重试、取消、过期与显示变化、真实旧状态保存重启、其他 Folder 不变。四向的混合 DPI 双向及上下跨屏、负坐标、屏幕空洞与受阻反向在业务轨迹中覆盖；最近放置与独立逐物理像素穷举对照，包含右头部障碍。

几何过期检查先提交后来有效的折叠状态，再确认旧方向草稿被拒绝且预览采用当前状态。恢复锁定检查使用真实备份和损坏主文件触发正式恢复路径，拒绝新会话、旧方向预览和提交，同时允许安全取消。

`--four-way-input-check` 使用实际系统鼠标／键盘操作样式选项、按钮、手柄和内容，核对 HWND、渲染、输入命中、状态及实际打开标记。八种组合逐一悬停检查完整名称；四向检查真实拖动／Esc、缩放、列表／网格、全文、滚轮、头部及桌面外部清除、双击打开。全文展开前后比较视口外像素，确认渲染变化全部留在所属视口；末行长名称滚轮到底后核对偏移、末端可见与真实点击。实际输入还覆盖样式失败重试、自动挪位预览后的取消与逐 Folder 重启恢复。

末行夹具先核对实际排序。中文文件名在当前 Windows 自然排序中位于 `zz` 后，因此其余项目使用数字前缀，保证末端快捷方式是实际最后一项；不把任意名称前缀当作排序事实。Esc 拖动取消通过实际按下／释放并保留 100 ms，覆盖正式桌面输入轮询。

本票“当前位置越界或与其他 Folder 冲突时，仅当前 Folder 寻找最近合法空位”更新了旧顶部缩放的直接拒绝规则。两项旧回归断言按独立算例调整：800 px 工作区底部增加 20 DIP 厚度时从 Y=492 移到 Y=472；头部 68、展示 720 的完整高度为 788，原 Y=20 时只上移到 Y=12。继续核对预览不提交、展示尺寸不缩水、其他 Folder 不变和重启恢复。
