# 开发与发布

本文供源码维护者使用。软件的日常操作见[仓库首页](../README.md)和[完整使用说明](使用说明.md)。

## 源码运行

需要 Windows 与 .NET 10 SDK。在仓库根目录双击 `run.cmd`，或执行：

```powershell
dotnet restore src/KageDesktopTool/KageDesktopTool.csproj --configfile NuGet.Config
dotnet run --project src/KageDesktopTool/KageDesktopTool.csproj --no-restore
```

## 构建与验证

业务检查与界面共用 `IDesktopWorkspace`，使用随机隔离目录。正式图标位于 `src/KageDesktopTool/Assets/`；修改 WPF 图像资源后使用 Rebuild 验证。

```powershell
dotnet restore tests/Kage.Workspace.Checks/Kage.Workspace.Checks.csproj --configfile NuGet.Config
dotnet run --project tests/Kage.Workspace.Checks --no-restore
dotnet build src/KageDesktopTool/KageDesktopTool.csproj -c Release -t:Rebuild
```

PowerShell 7 下运行 `./tools/windows/verify-ci.ps1` 可执行与 GitHub Windows CI 相同的仓库约束、隔离业务分组、独立构建与执行器契约检查。交互检查清单用 `./verify-release.ps1 -List` 查看，预览执行计划用 `-Plan`。新增检查需要登记 `tools/windows/checks.json`，遗漏入口会使 CI 失败。

Windows 输入、Shell、回收站及桌面恢复检查需在当前用户的交互式 Windows 会话串行执行。单项检查用 `verify-release.ps1 -OnlyCheck <名称>`，毛玻璃分组用 `-Suite frosted`。每次运行保存独立记录，超时与中断后可用 `-Resume <运行ID>` 恢复。系统设置组合、稳定人工检查包与恢复步骤见[Windows 验证与交接](retro/windows-verification.md)。当前发布覆盖见[1.1.3 发布验收记录](verification/release-1.1.3.md)。

## 生成发布包

`publish.ps1` 从项目读取版本，使用 Windows x64 自包含发布配置，生成完整目录、ZIP、逐文件 `SHA256SUMS.txt` 和 ZIP 的 SHA256。构建需从 NuGet 获取运行时包；已有发布目录会被拒绝覆盖。

```powershell
./publish.ps1
./verify-release.ps1
./verify-archive.ps1
./verify-user-launch.ps1
```

上述脚本直接在 PowerShell 中执行，不依赖额外命令包装工具。默认目录为 `releases/KageDesktopTool-win-x64-<项目版本>/`。已有同版本产物时，发布需指定新的 `-OutputDirectory releases/<新目录>`，验收脚本则传入相同的 `-PackageDirectory`。发布完成后自动删除本次临时构建目录；ZIP 验收使用含空格的随机解压目录，核对完自动清理。

组合验收会操作鼠标、托盘和 Explorer，执行时需留出输入；普通启动验收要求已有实例退出、实际用户状态可用且无待恢复操作。检查通过仅代表所记录的实际环境与覆盖范围。

## 维护文件

- `src/Kage.Workspace/`：业务接口、状态存储和真实目录操作。
- `src/KageDesktopTool/`：WPF、桌面宿主、托盘、热键及 Windows 适配。
- `tests/`：业务回归；`tools/`：图标生成器、发布共用函数和系统菜单修复工具。
- `.scratch/`：后续开发的临时票据、构建与验收输出；本次已完成的票据和历史产物已清理。`docs/verification/` 只保留当前最终发布验收记录，历史规格与验收文档可从 Git 历史查阅。
- `releases/`、构建缓存和隔离验收产物忽略 Git；发布 ZIP 需单独提供下载。

系统菜单修复的唯一一份本机还原资料位于 `local-backups/windows-shell-latency/final-backup-v2/`，忽略 Git，独立于临时开发目录。使用前阅读[系统菜单恢复说明](maintenance/windows-shell-menu.md)。
