# KageDesktopTool 使用说明

## 安装与运行

本包用于 Windows x64，包含 .NET 10 与 WPF 运行时。解压整个压缩包到固定目录，例如 `D:\工具\KageDesktopTool\`，双击其中的 `KageDesktopTool.exe`。无需安装 SDK 或输入开发命令；保留同目录中的 DLL、运行时及 `Assets` 文件夹。当前已实际验收的系统与显示配置见仓库的 13 验收记录；ARM64、32 位 Windows 和其他系统未验收。

程序显示托盘图标，首次运行没有示例文件或 Folder。默认存储根目录为 `D:\KageFiles\`；第一次创建时检查并建立目录。该位置不可用时，在托盘“设置”中明确选择可用目录，不会静默改用其他位置。

状态保存在 `%LOCALAPPDATA%\KageDesktopTool\workspace.json` 及相邻备份，与程序位置、内容文件夹分开。正式包读取这一实际用户状态；原型目录及原型设置不会被自动导入或修改。不要把状态目录或内容目录作为程序升级的替换目录。

## 创建、查看与整理

- 托盘“新建 Folder”或 `Ctrl+Alt+K` 创建同名真实内容文件夹。名称遵守 Windows 规则；同名可保留两份自动编号、跳过或取消。热键占用时仍可从托盘创建。
- 点击头部右侧展开／折叠，多 Folder 可同时展开。“查看”提供网格／列表、16／32／48／96 DIP 四档图标及名称、修改日期、大小、自定义排序。新建 Folder 默认网格大 48、列表中 32；每个 Folder 独立保存设置。自动排序目录优先，名称按数字自然排序，大小使用文件或快捷方式自身字节数。
- 双击图像或文件名打开实际文件、程序、快捷方式目标或子目录。快捷方式标签隐藏 `.lnk`，图像在工具内去掉系统箭头，实际文件名与目标保持原样。右键图标在资源管理器定位当前单项／多项选择，并由系统展示原生菜单；Windows 11 按系统当前设置使用现代或传统菜单，“显示更多选项”可访问传统扩展。右键头部或空白处管理 Folder。菜单操作结束后自动刷新项目及计数。
- Ctrl 点击切换选择，Shift 点击扩展连续范围；从空白处或右侧留白拖出选框，Ctrl 切换命中项目、Shift 扩展选择，靠近上下边缘自动滚动。释放后保留选择，刷新时仍存在的项目保持选择。
- 同一 Folder 内拖动项目到插入标记处，自动切换紧凑的自定义顺序；多选保持相对顺序。未跨过拖动阈值、原位释放或 Esc 取消不改顺序。切回自动排序后仍可恢复最近手动顺序，新增项目追加、删除项目清理，可靠识别的改名保留位置。内部重排不移动实际文件。
- 拖动头部移动位置，沿屏幕或其他 Folder 边缘滑动；右下角调整尺寸。位置、尺寸、展开和查看方式自动保存。空间不足时暂未展示，在设置中“刷新展示”或直接打开内容文件夹，空间恢复后重新显示。
- 从桌面、Explorer 或另一个 Folder 多选拖入，或从展示部分拖出到实际目录，均为**真实移动**，原路径会改变。快捷方式只移动 `.lnk` 自身。冲突选择保留两份、跳过或取消；取消保留已完成项目。结果窗口列出逐项实际路径，失败时核对源与可能已复制的目标，不盲目再次移动。未识别的虚拟位置和重解析路径不会作为有效目标。
- 头部右键“重命名…”同时更改真实目录，保留内容、位置和外观。“删除…”必须选择“保留内容”或“一同删除”：前者只移除工具入口，在实际用户桌面生成内容文件夹快捷方式；后者将完整目录及内容放入回收站，不永久删除。取消保留现状。
- 头部右键或设置中的“外观…”支持预设色、Windows 调色盘、RGB、HEX 和透明度预览。取消、Esc 或关闭恢复原值；“应用”成功后才保存。透明度只影响背景。托盘“图标方案”保存 A／B／C／D 选择，默认 D；EXE 本身内置 D 图标。

## 更换目录与故障恢复

在设置中选择新存储根目录，点击“迁移并保存目录”。活动及保留内容全部迁移，工具创建的快捷方式更新目标；全部完成后才切换设置。同名冲突先处理或换目标目录。迁移期间其他修改暂停，可取消后续执行；失败或取消会尝试恢复原位置。

中断或恢复不完整时，重启显示待恢复状态、每项实际路径和定位入口，暂停修改。先核对实际内容，再点击恢复操作；恢复失败仍保留可重试记录。不要手动删除迁移日志、内部 `.kage-folder-id` 归属标识或只因目标有内容就删掉源目录。原根目录离线时，“离线时另选新建目录”仅明确改变后续新建位置，已有内容继续关联旧路径，并未迁移。

状态损坏时只读加载可用备份并说明原因。核对后明确“恢复状态备份”，保留损坏证据；不会把损坏状态当作空工作区覆盖。

## 自启、退出与升级

设置中选择自启开关，再点击“应用自启选择”，核对结果。启动项使用当前包内 EXE 的完整路径，支持含空格的位置。重复启动只打开已有实例的设置；关闭设置后仍在托盘运行。托盘“退出”释放窗口、热键及刷新，保留真实内容。

升级或移动程序位置：先在旧包设置中关闭自启并应用，然后从托盘退出；备份状态目录及重要内容，将**整个新包**解压到最终目录，从那里启动。检查现有 Folder、根目录和实际内容，再按需要开启自启并应用，确认结果成功后移除旧程序包。若旧包已不可用，在新包中重新应用自启选择；启动只会提示旧路径差异，不会擅自重写。不要仅替换 EXE、不要在程序运行时覆盖其目录。回退程序时需核对状态格式；备份状态不代替内容备份。

## 暂时不可见或不可用

`Win+D` 后桌面 Folder 应继续可用；Explorer 重启后程序恢复桌面挂接、托盘及输入。宿主暂不可用时，保留记录和文件，通过托盘设置查看说明；等待桌面恢复或使用“刷新展示”。实际目录离线、空间不足和待恢复状态均明确显示，不代表文件已删除。多显示器与混合 DPI 有业务轨迹检查，但实际多屏、拔屏和系统显示配置切换尚未验收。

本包包含固定版本的运行时，升级运行时需要换用重新发布的完整包。发布方式依据 [Microsoft 自包含发布说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/#publish-as-self-contained)。
