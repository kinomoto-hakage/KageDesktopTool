# Windows 桌面 Folder 工具需求草案

Status: confirmed

## 目标

供用户本人在 Windows 上直接整理桌面文件和快捷方式，提供类似手机主屏幕 Folder 的展开体验，同时实际移动文件。

## 已确认的使用流程

### 创建与存储

- 通过 `Ctrl+Alt+K` 或系统托盘右键菜单创建桌面 Folder。
- 存储根目录默认为 `D:\KageFiles\`，用户可以选择和修改。
- 每个桌面 Folder 对应存储根目录下的一个同名内容文件夹。
- 修改存储根目录时，迁移全部现有内容文件夹。
- 重命名桌面 Folder 时应保持其与内容文件夹同名。

### 展示与操作

- 桌面 Folder 分为头部和展示部分，默认灰色半透明。
- 折叠时只显示头部：名称、内容文件数、下拉样式的倒三角展开按钮；展开后按钮用于折叠。
- 展示部分在头部正下方展开，多个 Folder 可以同时展开，点击其他位置不自动折叠。
- 创建、恢复位置、移动、调整尺寸和展开后的所有可见 Folder 均不得互相重叠。
- 展开时优先保留当前头部位置，为冲突的其他 Folder 查找附近空位；无法容纳时取消展开。移动和缩放拒绝会造成重叠的请求。
- 头部与展示部分宽度保持一致；折叠时调节头部宽高，展开时调节共享宽度和展示部分高度，保存尺寸。
- 展示部分的图标由 Windows Shell 读取，使用与资源管理器文件夹中相同的文件关联、文件夹及快捷方式图标。
- 支持重命名、背景颜色和透明度设置。使用调色盘，同时支持输入 RGB 和 HEX；使用滑块实时显示背景透明度，保持文字和图标清晰。
- 展示部分提供列表和网格查看方式，支持一键切换。
- 将文件或快捷方式拖入 Folder 时，实际移动到对应的内容文件夹。
- 从展示部分拖到桌面空白处时，实际移动到桌面。
- 支持从展示部分拖到资源管理器中的其他目录，以及批量拖拽。
- 同名冲突提供“保留两份并自动编号”“跳过”“取消”，默认不覆盖。

### 删除

用户删除桌面 Folder 时选择以下一种方式：

1. **保留内容**：保留内容文件夹及其中的内容，移除工具的桌面 Folder 展示，并在桌面创建指向该内容文件夹的快捷方式。内容不迁回桌面。
2. **一同删除**：将整个内容文件夹连同内容放入回收站，并移除工具的桌面 Folder 展示。

### 运行生命周期

- 使用系统托盘图标，右键菜单提供新建、设置和退出。
- 应用和托盘图标采用用户选定的 D「K 文件夹」方案；保留其他三套候选供切换比较。
- 关闭设置窗口后继续在后台运行。
- 支持开启／关闭开机自动运行。
- 通过系统托盘菜单退出后，桌面 Folder 展示消失，内容仍保存在存储目录。
- 再次启动恢复桌面 Folder 展示和已保存的尺寸。

## 已确认的补充规则

- 迁移失败或取消时停止迁移，保留原根目录配置并尝试移回已迁移内容；恢复不完整时展示实际位置及未恢复项目，不报告成功。
- 展示部分同步反映内容文件夹中被其他程序新增、删除或重命名的项目；普通子文件夹双击使用资源管理器打开，首版不提供嵌套桌面 Folder。
- 桌面 Folder 可自由拖动调整位置，保存位置并在重启时恢复；显示区域变化时调整到可见位置。

## 原型需要回答的问题

- 桌面 Folder 在 `Win+D` 后能否继续显示和接收操作。
- 正常应用覆盖、头部与展开的展示部分的窗口层次和焦点是否符合预期。
- 原生桌面与展示部分之间的拖拽是否能可靠执行实际移动。
- Explorer 重启、多显示器和 DPI 变化时能否恢复可操作的展示。

技术核查见 [桌面集成事实核查](desktop-integration.md)。本草案未将任何 Explorer 私有窗口结构视为稳定公开接口，也未确定最终桌面宿主实现。

## 后续验收重点

- 验证文件移动后的实际路径和内容，而不仅检查图标变化。
- 验证同名冲突不会静默覆盖文件。
- 验证保留内容只创建快捷方式，一同删除走回收站。
- 验证迁移及恢复过程中的文件位置与配置一致性。
- 验证重启恢复、快捷键、系统托盘和开机启动开关。
- 结合桌面交互原型人工验证视觉、拖拽、调色盘、透明度实时效果、多个 Folder 的不重叠布局及尺寸保存。

## 范围说明

- 已确认仅支持 Windows，供用户本人使用。
- 本文记录用户已确认的需求；最终桌面宿主实现待原型验证后确定。
