**实现内容（What to build）：** 在桌面、资源管理器及多个 Folder 之间真实移动文件、快捷方式和普通子文件夹，支持多选、同名选择、取消与逐项结果，内容与展示保持一致。

**阻塞关系（Blocked by）：** 05「原生内容查看、多 Folder 展开及不重叠布局」

## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：将真实内容批量移入 Folder 并处理同名冲突

- [ ] 拖入实际文件系统项目后，源／目标位置和内容与移动结果一致；不保留原型白名单限制。
- [ ] 移动快捷方式本身，不移动它指向的文件；普通子文件夹作为项目移动，不转换成嵌套桌面 Folder。
- [ ] 同名时提供保留两份编号、跳过、取消；不静默覆盖。文件、目录及快捷方式冲突均有正确结果。
- [ ] 批量列出成功、跳过、取消和失败项目；取消停止后续项目，已完成的普通移动保留并明确列出。
- [ ] 文件占用、权限不足、目标不可用、自身／子目录移动、跨本地磁盘场景的结果可观察，不把仅获得拖放效果标志当作全部成功。
- [ ] 操作不在拖动／布局线程中同步执行；移动后项目、计数和图标更新，状态提交失败与移动失败可区分。
- [ ] 在共用操作 interface 下用真实临时目录验证字节内容、源消失及结果；Windows 会话验证从真实桌面和资源管理器多选拖入。

## 验收：移出到桌面、资源管理器或另一个 Folder

- [ ] 拖到桌面空白处时，目标是 Windows 当前用户的实际桌面目录，兼容目录重定向，不拼接固定用户名路径。
- [ ] 能拖到资源管理器中的明确目标，以及其他 Folder；支持多选文件、快捷方式和普通子文件夹。
- [ ] 原生拖放双方只执行一次移动；取消、部分完成或接收方失败时，不凭全局效果标志删除所有源项目或伪造目标路径。
- [ ] 延续保留两份、跳过、取消及逐项结果；移动后两边的实际内容、计数和展示一致。
- [ ] 快捷方式只移动自身；同一目录、无效目标、占用／权限失败及跨本地磁盘有正确结果。
- [ ] 临时目录检查路径与字节内容；真实桌面／资源管理器会话验证多选拖出、取消及 Folder 间移动。
