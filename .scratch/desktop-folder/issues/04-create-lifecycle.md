## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。
- 稳定标识、有版本的状态和共用操作 interface 随创建／重启闭环建立；不生成示例文件或自动导入原型数据。完整内容和布局由 05 扩展。

## 验收：启动正式程序、创建 Folder 并重启恢复

- [x] 用户可启动正式程序，从托盘和 `Ctrl+Alt+K` 创建 Folder；磁盘上存在对应真实目录，头部名称一致。
- [x] 默认或保存的根目录不可用时说明原因；用户选择另一目录后可以创建，不静默改用未选择的目录。
- [x] 名称与路径遵守 Windows 规则，同名创建提供保留两份编号、跳过、取消，不覆盖现有目录。
- [x] 一个目录创建或状态保存失败时返回实际结果，不伪造成功，不丢失已存在的内容及关联。
- [x] 退出后内容目录保留；再次启动恢复稳定标识、名称和头部位置。保存中断或状态损坏不会被当作空工作区悄悄覆盖。
- [x] 多个初始头部放置与恢复不重叠；暂时容纳不下时保留记录及内容并说明展示状态。
- [x] 重复启动只有一个有效实例；热键被占用时仍能通过托盘创建并得到说明；关闭设置窗口不退出。
- [x] 主业务检查通过与 UI 共用的操作 interface，在隔离目录验收创建和重启；Windows 会话检查托盘、热键及透明头部，不触碰个人内容作为测试夹具。

## 验收：从设置控制开机自启并保持后台运行

- [x] 没有已保存的开启选择时不注册自启；开启／关闭同时更新实际用户级启动配置与保存的偏好。
- [x] 更新失败时说明具体结果，界面不能只改变开关却伪装注册成功。
- [x] 重启读取选择，重复切换不制造重复启动项；自启目标指向可运行的程序，并能在发布包位置安排下正常启动。
- [x] 关闭设置窗口仍保留托盘和 Folder；明确退出释放窗口、热键和监听，内容目录仍存在。
- [x] 通过设置操作 interface 检查保存及平台更新失败；Windows 验收使用可恢复的临时启动配置，验证实际开关效果并清理测试变化。

## Answer

- 正式源码位于 `src/Kage.Workspace/` 与 `src/KageDesktopTool/`，不加载原型示例数据。托盘、热键和设置共用 `IDesktopWorkspace`；真实目录、稳定标识、版本状态、原子提交／备份以及中断核对随闭环建立。
- 新建目录采用排他创建和隐藏归属标识，避免并发同名及清理失败时误认领外部目录。标识原子写入；不完整标识经用户核对可修复并保留证据，不覆盖其他有效标识。旧根目录离线时另选目录仅用于新建，保留既有关联的原路径。
- 当前用户级自启实际注册与偏好同步提交并核对，失败尝试恢复旧配置；单实例通过用户隔离的 Mutex／命名管道转交设置请求，明确退出释放托盘、窗口、热键和后台刷新。
