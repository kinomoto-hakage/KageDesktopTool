## 上下文与范围

- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：实时调整 Folder 外观并保存图标选择

- [x] 默认灰色半透明，调色盘、RGB 三分量和 HEX 输入均可更新同一个颜色值。
- [x] 无效输入清楚提示且不提交无效颜色；有效输入互相同步。
- [x] 滑块实时改变背景透明度，文字和 Windows 图标保持清晰，不改变内容路径或布局位置。
- [x] 取消恢复打开前的颜色及透明度；应用保存，重启恢复每个 Folder 的独立外观。
- [x] 默认 D「K 文件夹」，保留 A／B／C 候选可切换；托盘及窗口采用保存的选择，发布包采用已选 D 作为内置应用图标。
- [x] 正常桌面会话中检查透明背景、文字／图标及调色盘焦点；通过共用设置操作 interface 验证应用、取消和保存失败结果。

## Answer

- 头部右键及设置列表提供“外观…”入口。预设色块、原生 Windows 调色盘、RGB／HEX 同步同一颜色，非法输入提示原因并禁用应用。背景透明度实时改变背景 alpha，文字及 Shell 图标不变淡；预览不写状态，不改变路径、位置或尺寸，后台刷新仍保留当前草稿。
- 共用 `IDesktopWorkspace` 外观会话控制应用和取消。取消、Esc 或关闭恢复打开前设置；应用先保存再更新快照，失败保留原记录和可重试草稿。每个 Folder 独立重启恢复；仅更新外观，保留编辑期间已提交的布局及查看方式，拒绝过期草稿覆盖新外观。
- 托盘“图标方案”保留 A／B／C／D，默认 D「K 文件夹」。选择成功保存后更新托盘、选中标记和全部已打开窗口；重启使用保存选择，失败保持原方案。发布 EXE 内置 D 图标经逐像素核对，四套资源随包提供。
- 正式 Debug／Release 构建均为 0 警告、0 错误；21 项业务检查通过。含空格路径 Release 检查包中，06 外观、05 内容布局及 04 生命周期真实会话均退出码 0；原生调色盘 owner／焦点和 WPF 透明预览已核对。详见 [验收记录](../../../docs/verification/06-appearance-and-icons.md) 及 [运行说明](../../../README.md)。完整发布由 13 继续交付。
