**阻塞关系（Blocked by）：** 05「原生内容查看、多 Folder 展开及不重叠布局」

## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：多显示器及 DPI 变化后保持布局和原生内容尺寸

- [x] 支持负坐标、相邻屏幕间移动及不同工作区域，物理坐标／WPF 逻辑尺寸换算一致；显示器空洞不被当作可用区域。
- [x] 每个窗口使用其实际显示环境的 DPI 和原生度量，改变缩放后重新排布网格、列表及命中区域。
- [x] 分辨率、主屏或显示器可用性改变后，超出可见范围的 Folder 寻找可见空位，不重叠、不丢失记录和内容。
- [x] 容纳不下时明确表示暂时不可见并提供恢复方式；显示区域恢复后能重新显示。
- [x] 跨屏及恢复后仍可沿边拖动、立即反向、调尺寸，列表左侧固定且文字／图标清晰。
- [x] 用记录的多屏／DPI 环境验证布局结果，并在实际可用显示配置下验收绘制和输入；无法实际覆盖的配置明确记录为未验证。

上述功能检查使用记录的业务显示环境及当前实际单屏 150% 会话；实际多屏、混合 DPI、拔屏与系统显示配置切换未验证，详见 Answer 及验收记录。勾选不代表这些硬件配置已经实际覆盖。

## Answer

- 按真实工作区并集检查整个窗口，负坐标和连续接缝可以通行，空洞／错位区域阻挡大步输入；每窗口快照提供目标 DPI，尺寸保持 DIP，输入保持物理像素。四种混合 DPI 配置的双向及上下跨屏通过，高到低接缝无自洽解时稳定使用头部原点所在屏幕。
- 显示环境变化后优先保留剩余屏中的可见位置，再恢复其他入口；容纳不下的记录、展开状态和字节保留，设置提供暂未展示说明、“刷新展示”和实际目录入口，空间恢复后自动重新展示。位置保存失败按新工作区临时展示并明确报告，旧 DPI 输入不能覆盖新环境。
- 直接重新枚举 Windows 工作区，监听显示及系统设置变化；重测对应实际屏的标题字体、图标网格及原生 ListView 行高。补偿 Explorer 宿主与目标屏的 DPI 差，同时换算绘制、根窗口尺寸及命中；Shell 图标使用足够大的原生图像并保留覆盖。
- 最终完整 52 项业务检查通过；Release 0 警告／0 错误。当前单屏 `(0, 0, 2560, 1528)`、150%／144 DPI 的绘制、内容选择、真实头部拖动、调尺寸、显示通知及反向输入通过，125%／150%／200% 注入度量的尺寸和命中检查通过；05／06／07 真实 Windows 回归通过。
- 实际多屏、负坐标屏幕、混合 DPI、物理拔屏、主屏和系统缩放／分辨率切换**未验证**；记录的业务轨迹与度量注入不代替这些硬件配置的实际验收。当前可用配置的截图已查看。
