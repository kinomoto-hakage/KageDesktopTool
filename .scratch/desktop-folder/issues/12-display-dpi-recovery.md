**实现内容（What to build）：** 在跨屏、负坐标、缩放、分辨率及显示器变化后保持原生内容尺寸、可见位置、不重叠布局和正确输入。

**阻塞关系（Blocked by）：** 05「原生内容查看、多 Folder 展开及不重叠布局」

## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：多显示器及 DPI 变化后保持布局和原生内容尺寸

- [ ] 支持负坐标、相邻屏幕间移动及不同工作区域，物理坐标／WPF 逻辑尺寸换算一致；显示器空洞不被当作可用区域。
- [ ] 每个窗口使用其实际显示环境的 DPI 和原生度量，改变缩放后重新排布网格、列表及命中区域。
- [ ] 分辨率、主屏或显示器可用性改变后，超出可见范围的 Folder 寻找可见空位，不重叠、不丢失记录和内容。
- [ ] 容纳不下时明确表示暂时不可见并提供恢复方式；显示区域恢复后能重新显示。
- [ ] 跨屏及恢复后仍可沿边拖动、立即反向、调尺寸，列表左侧固定且文字／图标清晰。
- [ ] 用记录的多屏／DPI 环境验证布局结果，并在实际可用显示配置下验收绘制和输入；无法实际覆盖的配置明确记录为未验证。
