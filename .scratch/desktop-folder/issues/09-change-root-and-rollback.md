## 验收：更换存储根目录、整体迁移并处理当场失败和取消

- [x] 设置可选择新目录；先验证可用性、路径关系及冲突，相同根目录视为无变化，拒绝目录迁入自身或子目录。
- [x] 全部清单和关联快捷方式目标完成后才切换正常根目录配置；“跳过”或部分完成不报告整体成功。
- [x] 支持真实跨本地磁盘迁移，目标内容确认完成后再完成对应源移除；不依赖同盘重命名来冒充跨盘支持。
- [x] 进度可见且可取消；迁移期间暂停会修改相关路径／映射的其他操作，避免并发更改迁移清单。
- [x] 逐项记录旧／新路径、执行／恢复和快捷方式目标变化，写入中断后仍有可供 10 消费的记录。
- [x] 当场失败或取消时停止继续迁移，保留旧配置并尝试恢复已迁移内容和快捷方式目标；未完全恢复的实际路径及状态保留，不报告成功。
- [x] 用真实临时目录验证完整迁移与字节内容；只对指定逐项失败／取消使用可控适配器；保存失败、冲突及恢复失败均有明确结果。
- [x] 跨盘环境不可用时明确记录该项未验证，不以同盘检查代替；本票交付的设置操作可独立演示成功和当场取消恢复。
