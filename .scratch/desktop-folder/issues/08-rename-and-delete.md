**阻塞关系（Blocked by）：** 04「创建真实 Folder、重启恢复并控制运行和自启」

## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：重命名 Folder 并保持目录、标识和状态一致

- [x] 有效名称使真实目录和头部名称同步改变，稳定标识不变，目录中的内容不丢失。
- [x] 同名提供保留两份编号、跳过、取消；编号后的实际目录名与展示名一致，不覆盖其他目录。
- [x] 无效名称、目录占用／权限不足或状态保存失败返回实际结果；不把显示名称先改好而忽略目录执行失败。
- [x] 已有目录监听在路径改变后继续反映内容；若完整内容展示尚未实施，后续读取仍使用更新后的稳定映射。
- [x] 重启后名称／实际路径一致，外观和位置不被重置。
- [x] 通过共用操作 interface 在真实临时目录验证成功、冲突、失败和保存异常；用户可通过头部菜单演示完整改名过程。

## 验收：删除 Folder 时保留快捷方式或整体进入回收站

- [x] 用户明确选择两种删除方式或取消，文件效果与所选方式一致。
- [x] 保留内容时目录及字节内容不移动到桌面；在 Windows 实际桌面成功创建对应快捷方式后，才移除工具的展示。
- [x] 桌面快捷方式同名时遵循编号、跳过、取消；创建失败或跳过导致未完成时，不能丢掉原可操作入口。
- [x] 保存保留目录与工具生成快捷方式的最小关联，以便 09 迁移目标；重启不自动复活已移除的入口。
- [x] 一同删除确认整个内容目录实际进回收站后再移除活动映射；取消或不能回收时不降级为永久删除。
- [x] 删除、快捷方式创建与状态提交失败可区分，保留实际路径和可恢复状态。
- [x] 用隔离目录及可替换的桌面目的地检查文件与快捷方式目标；Windows 原生集成检查仅回收临时夹具，避免用假适配器替代全部回收效果。
