**实现内容（What to build）：** 在桌面、资源管理器及多个 Folder 之间真实移动文件、快捷方式和普通子文件夹，支持多选、同名选择、取消与逐项结果，内容与展示保持一致。

**阻塞关系（Blocked by）：** 05「原生内容查看、多 Folder 展开及不重叠布局」

## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：将真实内容批量移入 Folder 并处理同名冲突

- [x] 拖入实际文件系统项目后，源／目标位置和内容与移动结果一致；不保留原型白名单限制。
- [x] 移动快捷方式本身，不移动它指向的文件；普通子文件夹作为项目移动，不转换成嵌套桌面 Folder。
- [x] 同名时提供保留两份编号、跳过、取消；不静默覆盖。文件、目录及快捷方式冲突均有正确结果。
- [x] 批量列出成功、跳过、取消和失败项目；取消停止后续项目，已完成的普通移动保留并明确列出。
- [x] 文件占用、权限不足、目标不可用、自身／子目录移动、跨本地磁盘场景的结果可观察，不把仅获得拖放效果标志当作全部成功。
- [x] 操作不在拖动／布局线程中同步执行；移动后项目、计数和图标更新，状态提交失败与移动失败可区分。
- [x] 在共用操作 interface 下用真实临时目录验证字节内容、源消失及结果；Windows 会话验证从真实桌面和资源管理器多选拖入。

## 验收：移出到桌面、资源管理器或另一个 Folder

- [x] 拖到桌面空白处时，目标是 Windows 当前用户的实际桌面目录，兼容目录重定向，不拼接固定用户名路径。
- [x] 能拖到资源管理器中的明确目标，以及其他 Folder；支持多选文件、快捷方式和普通子文件夹。
- [x] 原生拖放双方只执行一次移动；取消、部分完成或接收方失败时，不凭全局效果标志删除所有源项目或伪造目标路径。
- [x] 延续保留两份、跳过、取消及逐项结果；移动后两边的实际内容、计数和展示一致。
- [x] 快捷方式只移动自身；同一目录、无效目标、占用／权限失败及跨本地磁盘有正确结果。
- [x] 临时目录检查路径与字节内容；真实桌面／资源管理器会话验证多选拖出、取消及 Folder 间移动。

## Answer

- 共用 `IDesktopWorkspace.MoveAsync` 后台执行双向批量真实移动，支持异步同名选择、逐项进度和取消；结果独立表达实际源／目标、各项结果与状态提交结果。快捷方式只移动自身，普通子目录不转换为桌面 Folder。
- 正式展示部分支持 Ctrl／Shift 多选和起拖保留已有选择；原生 OLE 接入实际桌面、Explorer 明确目录内容区及 Folder。源与目标不会因全局效果标志重复移动或删除未成功项目；桌面从 Windows 获取，本机实际重定向到 D 盘。结果窗口明确列出成功、跳过、取消、失败及实际位置，真实冲突对话框提供三种选择。
- 同名编号排他处理，不覆盖；自身／子目录、同目录、目标失联、文件占用及真实 ACL 失败均可观察。跨盘目录完整复制并核对默认／命名数据流后才删除源；失败／取消保留两边已有内容。重解析路径明确不支持，需选择实际目录。
- 25 项全套共用接口检查、Release 构建、07 实际鼠标/OLE 桌面及 Explorer 检查，以及 04／05／06 真实 Windows 回归均通过。日志和夹具不纳入 Git；权限与窗口已恢复，夹具已清理。本地检查包已更新到 `.scratch/desktop-folder/verification/发布包 含空格/`，完整发布仍由 13 交付。详见 [验收记录](../../../docs/verification/07-file-moves-and-conflicts.md)。
