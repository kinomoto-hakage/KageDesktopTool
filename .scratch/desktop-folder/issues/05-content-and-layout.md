## 上下文与范围

- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。
- 本票交付完整查看及布局交互；真实内容移动由 07 交付，颜色及图标的自定义由 06 交付。

## 验收：展开真实内容并切换原生密度的网格和列表

- [ ] 展示真实文件、快捷方式和普通子文件夹；图标使用实际路径对应的 Windows Shell 图标及覆盖，不使用通用占位符替代。
- [ ] 头部计数为直接文件数，快捷方式计为文件；文件夹仍展示且双击使用资源管理器打开。
- [ ] 网格使用系统网格尺寸及标题字体，图标和文件名在完整等尺寸格子内居中，长名称换行／必要时省略，项间距一致。
- [ ] 列表使用本机原生小图标列表行高和字体；行宽随视口伸缩，图标／文件名左侧固定，不保存刷新时的固定行宽。
- [ ] 一键切换两种查看方式并保存；短名、长名、不同文件类型和选择高亮下均保持正确布局。
- [ ] 双击文件使用系统默认程序；枚举和图标读取失败时显示实际结果，不冻结桌面输入。
- [ ] 外部新增、删除、重命名更新项目、计数及失效图标；目录失联时保留 Folder 记录并明确说明，不自动生成空目录冒充原数据。
- [ ] 在真实 WPF 排列结果上检查格子中心、间距、行高和反复加宽／缩窄的零左侧偏移；以真实临时目录验证外部变化及打开目标。

## 验收：多 Folder 展开、拖动和调尺寸保持不重叠

- [ ] 多个 Folder 同时展开，头部与展示部分等宽；关闭／折叠一个不会折叠其他 Folder。
- [ ] 拖动以相邻输入的屏幕像素差移动；受阻时更新锚点，不累积无效位移；丢失鼠标捕获时结束拖动。
- [ ] 屏幕四边、折叠和展开 Folder 的四向接触下均可立即反向及沿边滑动，不穿越其他 Folder。
- [ ] 展开优先保持本头部位置，为冲突的其他 Folder 查找附近空位；空间不足则恢复原布局并取消展开。
- [ ] 折叠时调整头部宽高；展开时调整共享宽度与内容区高度，左侧位置不变；不提交会导致重叠的尺寸。
- [ ] 位置、尺寸和展开状态重启恢复；无法容纳的 Folder 保留记录及内容，提供重新恢复展示的入口。
- [ ] 布局处理不触发同步目录枚举、图标读取或状态文件写入来拖慢每次鼠标移动。
- [ ] 轨迹回放覆盖受阻后反向一像素、沿边滑动和不重叠；真实窗口边界及 WPF 内容布局检查共同验证结果。
