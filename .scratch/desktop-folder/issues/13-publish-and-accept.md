## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：交付可直接运行的 Windows 包并完成整体验收

- [ ] 发布包可直接启动，内置 D 应用图标和必要资源；依赖、运行及升级／替换程序位置的说明真实可执行，不要求用开发命令日常使用。
- [ ] 正式包加载实际用户设置，不生成示例文件，不自动更改原型数据；内容目录和持久状态与发布位置保持合理分离。
- [ ] 设置及自启指向最终可运行位置；重复启动、关闭设置及明确退出行为正确。
- [ ] 对正式包完成创建、双向批量移动及冲突、重命名、两种删除、根迁移及失败／中断恢复的完整流程验收，实际文件与结果一致。
- [ ] 对正式包检查多 Folder 布局、原生网格／列表、外观预览、`Win+D`、Explorer 恢复及实际可用显示配置。
- [ ] 已有业务、文件操作、恢复、拖动和 WPF 布局回归继续通过；每票已承担自己的测试，此处增加组合流程及发布产物验证。
- [ ] 使用说明覆盖真实文件移动、保留内容与回收、目录迁移／恢复、自启开关及临时不可见／不可用状态；不把未验证的 Windows 配置标为通过。
