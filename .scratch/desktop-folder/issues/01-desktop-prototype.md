# 验证原生桌面 Folder 集成

Type: prototype
Status: resolved

## 目标

验证真正桌面上的头部与下方展示区、多 Folder 不重叠布局、“显示桌面”行为与拖拽，解决最终技术方案的不确定性。

## 原型指针

- 分支：`codex/prototype/desktop-folder`。
- 项目：`prototypes/DesktopFolderPrototype/`。
- [需求](../requirements.md)
- [实验结论与待验证项](../prototype-verdict.md)

## 已完成

- 构建原生 WPF 原型，提供头部与下方展示区、列表／网格切换、托盘和全局快捷键。
- 提供受限于原型示例数据的实际移动、重命名、保留内容快捷方式及回收站操作。
- 在当前交互会话中核查宿主挂接、“显示桌面”后的窗口命中和实际绘制。
- 保存临时位置、尺寸和样式状态，保留人工验收入口。

## 下一步

原型方案已由用户确认。将需求和原型结论合成为正式规格，再拆分具有阻塞关系的实现任务。文件操作可靠性、目录迁移、持久化、开机自启及桌面兼容性验证纳入正式实现；原型继续保留为对照来源。
