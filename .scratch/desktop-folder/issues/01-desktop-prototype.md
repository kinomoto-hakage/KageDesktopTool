# 验证原生桌面 Folder 集成

Type: prototype
Status: needs-interactive-validation

## 目标

验证真正桌面上的头部与下方展示区、多 Folder 不重叠布局、“显示桌面”行为与拖拽，解决最终技术方案的不确定性。

## 原型指针

- 分支：`codex/prototype/desktop-folder`。
- 项目：`prototypes/DesktopFolderPrototype/`。
- [需求](../requirements.md)
- [实验结论与待验证项](../prototype-verdict.md)

## 已完成

- 构建原生 WPF 原型，提供头部与下方展示区、列表／网格切换、托盘和全局快捷键。
- 提供受限于原型示例数据的实际移动、重命名、保留内容快捷方式及回收站操作。
- 在当前交互会话中核查宿主挂接、“显示桌面”后的窗口命中和实际绘制。
- 保存临时位置、尺寸和样式状态，保留人工验收入口。

## 下一步

按第二版原型说明验收布局、拖拽和外观控件；记录判断后确定正式实现方案，再形成实现规格和任务。尚未验证的交互不计为通过。

## Comments

- 第一版透明分层子窗口未正常绘制；第二版补上 Windows 10 兼容声明后，已实测正常绘制半透明背景。第一版限制已解除。
- 第二版改用头部下方内联展示，支持多个 Folder 同时展开及不重叠布局；原生图标、调色盘和实时透明度滑块已加入。
- 用户选择 D「K 文件夹」图标，已作为应用及托盘默认图标。
