## 上下文与范围

- 桌面 Folder 是头部与下方展示部分，对应存储根目录中的同名真实内容文件夹，沿用用户已验收的原型行为。
- 业务操作经共用的桌面整理 interface，检查实际文件和状态；Windows 会话能力另做真实验收。原型分支为 `codex/prototype/desktop-folder`。

## 验收：中断后恢复迁移并定位未恢复的真实内容

- [ ] 启动先检查未完成记录，核对实际目录和快捷方式状态，再决定恢复／显示状态，不直接套用旧或新全局路径。
- [ ] 在执行前、部分目录完成、快捷方式更新、配置提交及恢复中断等阶段退出后重启，都能判断实际执行结果。
- [ ] 恢复不完整时显示实际路径和未恢复项目，能打开现有内容位置并重试恢复；禁止不知情的路径修改继续扩大不一致。
- [ ] 重复启动或重复恢复不重复覆盖、复制或删除已经处理的内容，稳定标识及活动／保留状态正确。
- [ ] 恢复到旧根目录及对应快捷方式目标后退出恢复状态；仍失败时保留可定位的证据，不伪造正常工作区。
- [ ] 通过共用操作 interface 和真实临时目录验证进程级中断／重新打开、逐项故障及恢复失败，检查字节内容和路径而非仅检查日志存在。
