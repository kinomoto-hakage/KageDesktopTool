# KageDesktopTool 正式实现规格

Type: spec
Status: ready-for-agent

Test-seam-review: pending

## 问题陈述（Problem Statement）

用户希望在自己的 Windows 电脑上直接整理桌面文件和快捷方式。普通桌面文件夹不能提供已确认的头部／下方展示区、多个 Folder 同时展开、半透明外观、不重叠布局，以及方便的拖入拖出体验。

用户已经通过原型确认产品外观和核心操作，且拖动受阻后的停滞、网格未居中、列表缩放后左侧偏移均已修复并验收。下一阶段需要把这些行为落实为可日常使用的程序，完成真实文件管理、存储根目录迁移及恢复、持久状态、开机自启和桌面兼容性处理。

## 解决方案（Solution）

开发供用户本人使用的 Windows 桌面整理工具。每个桌面 Folder 由头部及其下方的展示部分组成，并对应存储根目录中的一个同名内容文件夹；移入、移出是真实文件移动。

存储根目录默认是 `D:\KageFiles\`，支持自定义和整体迁移。删除桌面 Folder 时，用户可以保留内容并在实际桌面留下对应内容文件夹的快捷方式，或将整个内容文件夹连同内容放入回收站。

正式界面采用已验收的灰色半透明默认样式、原生文件图标、列表／网格切换、调色盘、RGB／HEX 输入、实时透明度滑块，以及 D「K 文件夹」应用和托盘图标。多个 Folder 可以同时展开，移动、缩放、展开和恢复均维持不重叠布局；碰到屏幕或其他 Folder 后可以沿边滑动，反向拖动立即响应。

## 实现决策（Implementation Decisions）

### 已验证的技术与界面基线

- 正式实现采用 C#、.NET 10、WPF 和必要的 Windows 适配器，沿用已验收的交互及多尺寸图标资源。
- 原型保留为行为与视觉的对照来源。正式模块增加可测试的文件操作、状态和恢复机制，去除示例数据启动流程及仅允许原型文件移入的限制。
- 以用户当前 Windows 环境为首要验收环境。当前桌面宿主实验能使用 Explorer 桌面窗口及透明分层子窗口；将此策略收敛在 Windows 桌面宿主适配器中，并验证“显示桌面”、重启及 DPI 行为。
- Explorer 内部窗口的名称和层次不作为其他模块的 interface。宿主不可用时保留数据与状态，通过托盘说明展示不可用并允许打开实际内容目录；恢复后重新挂接，不把成功找到窗口等同于完整交互通过。

### 模块与主要测试入口（seam）

| 模块 | interface 与责任 | 实际变化及测试方式 |
| --- | --- | --- |
| 桌面整理模块 | 接收创建、重命名、移动、删除、迁移、布局和设置等操作；返回工作区快照、逐项结果及进度／恢复状态 | 界面、托盘、热键和主业务测试共用这个主要 seam；隐藏路径处理、冲突、状态提交及恢复次序 |
| Windows 文件操作适配器 | 执行真实移动、回收站操作、快捷方式创建和目标更新；返回实际执行结果 | 生产使用 Windows 操作；集成测试使用真实临时目录，恢复测试使用可控的逐项失败／取消适配器 |
| 本地状态适配器 | 读取和保存有版本的工作区状态，以及未完成操作记录 | 生产与集成测试使用真实存储；故障测试可在提交时注入失败 |
| Windows 桌面适配器 | 提供显示区域／DPI、桌面宿主、原生图标与字体／网格尺寸、托盘、热键及自启能力 | 隔离平台调用；通过真实 Windows 会话和记录的环境变化验证 |
| WPF 展示模块 | 把快照绘制为头部和展示部分，把输入转换为桌面整理模块的操作 | 在真实布局结果上检查中心、间距、行高和左侧锚点；完整桌面效果单独验收 |

主要 seam 是桌面整理模块的 interface，而不是单个按钮、文件系统调用或内部辅助方法。调用者表达用户意图并处理结果，文件操作与提交次序集中在模块内。内部 seam 仅在 Windows 能力或可控故障确实需要不同适配器时引入。

interface 至少表达操作目标、用户冲突选择、取消、逐项成功／跳过／失败、配置提交结果和恢复状态。读快照和订阅变化用于展示，不要求调用者读取内部存储格式。

### 状态与运行生命周期

- 每个桌面 Folder 具有稳定标识；名称、根目录下的内容目录映射、显示位置、头部尺寸、展示部分高度、展开状态、查看方式、背景颜色和透明度是可持久状态。
- 应用状态包含格式版本、存储根目录、自启选择及图标方案。状态放在当前用户的本地应用数据位置，与发布文件及内容文件区分。
- 保存使用临时提交及可恢复的最近有效状态，避免写入中断后把损坏状态当作空工作区。重启首先检查未完成文件操作／迁移记录，再恢复正常操作。
- 首次运行不创建示例文件。约定目录不可用时提供目录选择和具体原因；不把另一个目录悄悄当作用户指定的根目录。
- 同一用户的正常运行只保留一个有效实例。再次启动转交已有实例的入口或设置请求，避免重复托盘、热键和状态写入。
- 自启由保存的开关决定；未设置时不注册自启，用户开启／关闭时同步更新本机用户级启动配置。注册失败时报告真实结果，不只更改界面开关。
- 关闭设置窗口不退出。明确退出时完成必要状态提交、结束监听、释放热键／托盘／窗口及 Windows 资源；内容目录继续存在。

### 名称、路径与真实文件操作

- 正常状态中名称与内容文件夹名一致，路径由根目录和名称确定。名称及路径遵守 Windows 规则，同名判断采用 Windows 文件系统语义。
- 操作成功后才提交对应名称或目录映射；状态提交失败与文件操作失败分别报告，并以实际文件位置和未完成记录恢复一致性。
- 移入文件或快捷方式本身，不解析快捷方式并移动其目标。普通子文件夹可以作为内容项目移动或打开；不把它自动转换成嵌套的桌面 Folder。
- 桌面目的地从 Windows 获取，支持被重定向的实际用户桌面，不拼接固定用户目录。移往资源管理器目录遵从用户明确选择的目标。
- 同名处理使用统一的“保留两份并自动编号／跳过／取消”选择。保留两份不覆盖已有项目；重命名产生的编号同步用于桌面名称与目录名。
- 批量操作返回逐项结果。普通批量移动中的取消停止后续项目，已经完成的移动保留并列入结果；根目录迁移采用专门的恢复规则。
- 文件占用、权限不足、目标不可用或非法自身／子目录移动是可见失败，不吞掉异常、不将未移动项目显示为完成。默认以当前用户权限运行。
- 文件操作和迁移不在拖动／布局主线程中同步执行。进度、取消和目录变化汇入工作区状态；目录扫描、图标加载和文件写入不由每次鼠标移动触发。

### 删除与保留内容

- 保留内容先创建指向现有内容文件夹的实际桌面快捷方式，处理同名冲突，成功后移除工具的展示。不将文件迁回桌面，也不把移除入口当作删除内容。
- 为后续根目录迁移保留内容目录及由工具生成的快捷方式的最小关联记录；不重新显示已移除的入口。
- 一同删除将完整内容文件夹放入回收站，确认实际操作完成后移除展示与活动映射。无法执行回收或操作取消时不降级为永久删除。
- 目录保留、快捷方式创建或回收失败时仍提供对应目录的实际状态和可操作入口；结果与状态提交失败要可区分。

### 根目录迁移与恢复

- 迁移清单覆盖所有现有内容文件夹，包括已移除入口但选择保留内容的目录；同步更新工具生成的相关快捷方式目标。迁移不会自动复活这些入口。
- 开始前检查新根目录可用性、路径关系和同名冲突。相同根目录视为无变化；不允许内容目录迁移进入自身或其子目录。
- 对整体迁移保持独占的修改次序，暂停会改变路径或内容映射的其他操作，避免多个入口同时改变迁移中的目录。
- 记录旧／新路径、每个内容目录的执行和恢复状态，以及快捷方式目标变化。支持跨本地磁盘迁移；确认目标内容完成后再完成相应源移除，不假定跨磁盘具有文件系统原子性。
- 根目录及正常映射仅在迁移清单全部完成后切换。冲突的“跳过”不能把整体迁移报告为完成；保持旧配置并说明未完成清单。
- 失败或取消时停止继续迁移，保留旧根目录配置并尝试恢复已经迁移的内容及快捷方式目标。
- 恢复不完整时进入明确的恢复状态：保留实际路径和未恢复项目，允许定位实际内容、查看结果并重试恢复，不用错误的全局路径掩盖已经移动的目录。
- 重启后依据未完成记录核对磁盘和快捷方式的实际状态，不盲目重复移动、覆盖文件或宣告迁移成功。

### 布局与内容展示

- 头部和展示部分属于同一个桌面 Folder。展开只改变该 Folder 的状态，其他已展开 Folder 不自动折叠。
- 布局在物理屏幕坐标与 WPF 逻辑尺寸之间显式换算。可用显示区域来自 Windows 工作区域；恢复、拖动、缩放和展开共享不重叠规则。
- 拖动采用相邻鼠标输入的屏幕像素差，并在受阻时仍更新锚点，避免积累无效位移。限制碰撞方向而保留切向位移，沿移动路径检查其他 Folder，丢失鼠标捕获时结束拖动。
- 展开优先保留当前头部位置，为冲突的其他 Folder 寻找附近空位；放不下则恢复此前布局并取消展开。缩放保持位置和左侧不变，只提交可容纳的尺寸。
- 屏幕变化后的恢复先寻找可见、无重叠的位置；仍容纳不下的 Folder 保留记录及内容，明确表示暂时不可见并提供恢复入口，不删除它的配置。
- 网格使用完整等尺寸格子，图标及文件名居中，间距来自系统图标网格，标题使用系统图标字体；长文件名换行并在必要时省略。
- 列表使用原生小图标列表测得的行高及系统字体，行宽随视口伸缩，图标列靠左固定，文件名列使用剩余宽度；不能保存创建时的固定行宽。
- 文件数指内容文件夹中的直接文件数量，快捷方式计为文件，普通子文件夹仍可展示和打开。目录变化更新项目、计数及失效图标缓存。
- 颜色使用调色盘和 RGB／HEX 输入；输入校验不把无效值提交到布局。背景透明度独立于文字和图标，滑块实时预览，取消恢复原值，应用后保存。

## 测试决策（Testing Decisions）

### 测试入口与原则

- 拟采用一个主要业务 seam：由界面、托盘、快捷键及自动测试共同调用桌面整理模块的操作 interface。该安排由本次规格明确列出，供用户核对。
- 好的测试检查用户可观察的结果：实际路径与内容、操作结果、可恢复状态、可见布局及持久设置；不把内部方法是否被调用、模块私有字段或与实现同构的模拟流程当作验收。
- 文件内容与状态一致性在应用操作层使用真实临时目录验证。需要复现失败／取消时，仅替换相应适配器；不把所有文件操作都替换为没有实际副作用的假实现。
- Windows 原生操作及桌面会话能力另做集成验证，覆盖其真实结果；纯模块检查不能替代原生拖拽、回收站、托盘或宿主行为。

### 按行为组织的验收

| 行为 | 主要检查 |
| --- | --- |
| 创建、重命名、重启 | 同名目录真实存在；标识保持稳定；名称／映射一致；保存失败和损坏状态能正确处理 |
| 移入、移出、Folder 之间移动 | 源与目标的实际位置及字节内容；快捷方式自身移动；批量结果、同名选择、占用及权限失败 |
| 保留内容 | 原目录和内容仍存在；实际桌面快捷方式能打开它；创建失败不移除可用入口；根迁移后目标正确 |
| 一同删除 | 测试目录实际进入回收站；取消或不能回收时内容未永久删除；展示和状态与真实结果一致 |
| 根目录迁移 | 全部清单完成后切换；跨本地磁盘；冲突、取消、逐项失败、恢复失败、状态提交失败和中断后重启 |
| 拖动与不重叠布局 | 四个屏幕方向和折叠／展开 Folder 四向接触；立即反向、沿边滑动、路径碰撞、空间不足和恢复布局 |
| 网格与列表 | 实际排列的图标及标题中心、系统间距；列表行高及图标尺寸；反复缩放左侧偏移为零 |
| 外观与设置 | RGB／HEX 校验、透明度实时预览、取消恢复、应用保存、图标选择和重启恢复 |
| 桌面与生命周期 | 当前 Windows 会话中的“显示桌面”、焦点、真实多选拖拽、Explorer 重启、托盘恢复、热键占用、重复启动及明确退出 |
| 显示环境 | 多显示器、负坐标、跨屏、DPI／分辨率变化；图标字体尺寸、窗口命中和可见位置均正确 |
| 发布与自启 | 发布包实际启动；依赖说明正确；用户级自启开关和失败反馈；关闭设置窗口后继续运行 |

### 现有测试先例与迁移方式

- 原型已有拖动轨迹回放，复现过受阻后无效位移累积，并覆盖四边、即时反向、沿边滑动及折叠／展开 Folder 的四向碰撞。这些输入和行为断言用于正式布局测试。
- 原型已有真实 WPF 测量／排列检查，曾检测到列表加宽后的 80 DIP 偏移。正式展示测试继续检查完整文件项的中心和反复缩放的零偏移，不能只检查属性被设为“居中”。
- 原型已有原生窗口父关系、实际边界、“显示桌面”后的命中及透明绘制预览检查。正式 Windows 集成验收保留这些证据类型，同时增加完整输入、恢复和发布场景。
- 文件移动、回收、整体迁移与中断恢复尚无完整生产级测试先例；围绕主要业务 seam 建立它们，不沿用原型的示例文件白名单作为正式功能约束。
- 文件操作测试创建隔离夹具，清理前校验最终路径范围；自启和窗口会话验证使用临时或可恢复配置，检查完成后恢复测试产生的环境变化。

## 范围外（Out of Scope）

- macOS、Linux、移动端及跨设备同步。
- 云端账号、多人共享、商业授权或在线服务。
- 嵌套的自定义桌面 Folder；普通子文件夹仍可以移动并由资源管理器打开。
- 把一个文件拖到另一个文件上自动创建 Folder；创建采用已确认的快捷键和托盘入口。
- 虚拟引用分组、复制替代已要求的移动、自动分类或监控桌面后自动搬运未选择的文件。
- 移动“此电脑”“回收站”等没有普通文件路径的系统虚拟桌面项目。
- 用永久删除替代回收站操作。
- 对所有 Windows 版本和第三方桌面替换程序作未经验证的兼容性承诺。
- 自动发布到应用商店、在线更新服务及本次规格之后才决定的新功能。
