# 桌面文件夹整理需求记录

## 已确认

- 使用者：用户本人。
- 支持平台：仅 Windows。
- 交互位置：直接在电脑桌面操作。
- 每个桌面 Folder 对应存储根目录下的一个同名内容文件夹；移入、移出会实际移动文件或快捷方式，改变其存放路径。
- 存储根目录默认为 `D:\KageFiles\`，支持用户自定义选择和修改。
- 支持新建和删除 Folder，以及移入、移出图标或文件。
- 删除 Folder 时提供两个选项：
  1. 保留内容：保留内容文件夹及内容，在桌面留下对应内容文件夹的快捷方式。
  2. 一同删除：将内容文件夹连同内容放入回收站。
- 展示：桌面 Folder 分为头部和下方展示部分；折叠时只显示名称、内容文件数、倒三角展开按钮。多个 Folder 可同时展开，点击外部不自动折叠。
- 自定义：桌面 Folder 支持尺寸调节、重命名、背景颜色和透明度设置。
- 查看方式：列表与网格，两者支持一键切换。
- 创建方式：`Ctrl+Alt+K`，或右下角系统托盘图标的右键菜单。
- 修改存储根目录时，迁移全部现有内容文件夹。
- 移出到桌面空白处时实际移动到桌面；支持拖入资源管理器中的其他目录以及批量拖拽。
- 头部与展示部分支持尺寸调节，宽度保持一致；折叠时调节头部宽高，展开时调节共享宽度和展示部分高度。
- 默认灰色半透明，创建、展开、移动、缩放和恢复后的 Folder 不能相互重叠。
- Windows Shell 提供真实文件图标；颜色使用调色盘并支持 RGB／HEX 输入；背景透明度使用实时滑块。
- 生成四套应用／托盘图标，用户选择 D「K 文件夹」为默认方案；保留 A、B、C 供切换。
- 移入、重命名和创建保留内容快捷方式遇到同名冲突时，提供“保留两份并自动编号”“跳过”“取消”，默认不覆盖。
- 关闭设置窗口后继续在后台运行；系统托盘菜单提供新建、设置和退出。
- 开机自动运行支持开启／关闭。
- 退出工具后桌面 Folder 展示消失，文件仍保存在存储根目录；再次启动恢复展示。

## 已确认的补充规则

- 存储根目录迁移失败或取消时，停止迁移，保留原根目录配置并尝试恢复已迁移内容；恢复不完整时明确显示实际位置和未恢复项目。
- 内容面板自动同步其他程序新增、删除和重命名的内容；普通子文件夹双击使用资源管理器打开，首版不提供嵌套桌面 Folder。
- 桌面 Folder 可以自由拖动，重启时恢复位置；显示区域变化导致位置不可见时调整到可见区域。
