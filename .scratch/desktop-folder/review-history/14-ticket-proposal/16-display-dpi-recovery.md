# 16: 多显示器及 DPI 变化后保持布局和原生内容尺寸

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 06
User stories: 26–32, 70

**实现内容（What to build）：** 用户跨屏放置 Folder，改变缩放、分辨率或显示器安排后，窗口和原生图标／列表尺寸仍正确，已有 Folder 在可见区域中保持不重叠并可操作。

**阻塞关系（Blocked by）：** 06「多 Folder 展开、拖动和调尺寸保持不重叠」提供统一物理坐标布局及恢复规则；05 的内容尺寸由该依赖链提供。

## 验收标准

- [ ] 支持负坐标、相邻屏幕间移动及不同工作区域，物理坐标／WPF 逻辑尺寸换算一致；显示器空洞不被当作可用区域。
- [ ] 每个窗口使用其实际显示环境的 DPI 和原生度量，改变缩放后重新排布网格、列表及命中区域。
- [ ] 分辨率、主屏或显示器可用性改变后，超出可见范围的 Folder 寻找可见空位，不重叠、不丢失记录和内容。
- [ ] 容纳不下时明确表示暂时不可见并提供恢复方式；显示区域恢复后能重新显示。
- [ ] 跨屏及恢复后仍可沿边拖动、立即反向、调尺寸，列表左侧固定且文字／图标清晰。
- [ ] 用记录的多屏／DPI 环境验证布局结果，并在实际可用显示配置下验收绘制和输入；无法实际覆盖的配置明确记录为未验证。

## 来源与交付检查

- 演示：跨屏移动 → 修改缩放／分辨率 → 移除显示器 → 重新接入 → 核对位置与输入。
