# 04: 启动正式程序、创建 Folder 并重启恢复

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: None
User stories: 1–9, 14, 25, 61–62, 64–66, 67, 71

**实现内容（What to build）：** 用户启动正式程序，通过托盘或快捷键命名并创建一个真实内容文件夹，看到灰色半透明头部，退出并再次启动后仍能看到同一个 Folder。建立正式程序的最小运行闭环及共用的桌面整理操作 interface，原型继续作为对照来源。

**阻塞关系（Blocked by）：** 无，可以首先实施。现有 01–03 为已完成的原型／缺陷记录，不作为新实现的阻塞项。

## 上下文与范围

- 每个桌面 Folder 对应存储根目录下的同名内容文件夹；默认根目录为 `D:\KageFiles\`，不可用时允许明确选择可用目录。
- 头部显示名称、直接文件数和倒三角，采用 D「K 文件夹」图标。完整内容展示由 05 扩展，复杂拖动布局由 06 扩展。
- 稳定标识、有版本的持久状态和共用操作 interface 随创建／重启闭环交付，界面、托盘和热键不各自实现创建副作用。
- 不自动创建示例文件，也不自动导入或修改原型数据。

## 验收标准

- [ ] 用户可启动正式程序，从托盘和 `Ctrl+Alt+K` 创建 Folder；磁盘上存在对应真实目录，头部名称一致。
- [ ] 默认或保存的根目录不可用时说明原因；用户选择另一目录后可以创建，不静默改用未选择的目录。
- [ ] 名称与路径遵守 Windows 规则，同名创建提供保留两份编号、跳过、取消，不覆盖现有目录。
- [ ] 一个目录创建或状态保存失败时返回实际结果，不伪造成功，不丢失已存在的内容及关联。
- [ ] 退出后内容目录保留；再次启动恢复稳定标识、名称和头部位置。保存中断或状态损坏不会被当作空工作区悄悄覆盖。
- [ ] 多个初始头部放置与恢复不重叠；暂时容纳不下时保留记录及内容并说明展示状态。
- [ ] 重复启动只有一个有效实例；热键被占用时仍能通过托盘创建并得到说明；关闭设置窗口不退出。
- [ ] 主业务检查通过与 UI 共用的操作 interface，在隔离目录验收创建和重启；Windows 会话检查托盘、热键及透明头部，不触碰个人内容作为测试夹具。

## 来源与交付检查

- 依据正式规格的创建、状态、生命周期及主要测试 seam；原型对照分支为 `codex/prototype/desktop-folder`。
- 演示：启动 → 创建 → 检查真实目录 → 退出 → 再启动看到同一个 Folder。
- 此票完成即提供可运行基线；后续票逐项增加行为，不把纯模块准备作为唯一交付。
