# 07: 实时调整 Folder 外观并保存图标选择

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 05
User stories: 8, 25, 37–41, 67

**实现内容（What to build）：** 用户从 Folder 菜单打开调色盘，以 RGB／HEX 精确设置颜色、实时预览透明度，应用或取消；选择应用／托盘图标后重启仍保持选择。

**阻塞关系（Blocked by）：** 05「展开真实内容并切换原生密度的网格和列表」使外观可以在完整头部、文件图标和标题上验收。

## 验收标准

- [ ] 默认灰色半透明，调色盘、RGB 三分量和 HEX 输入均可更新同一个颜色值。
- [ ] 无效输入清楚提示且不提交无效颜色；有效输入互相同步。
- [ ] 滑块实时改变背景透明度，文字和 Windows 图标保持清晰，不改变内容路径或布局位置。
- [ ] 取消恢复打开前的颜色及透明度；应用保存，重启恢复每个 Folder 的独立外观。
- [ ] 默认 D「K 文件夹」，保留 A／B／C 候选可切换；托盘及窗口采用保存的选择，发布包采用已选 D 作为内置应用图标。
- [ ] 正常桌面会话中检查透明背景、文字／图标及调色盘焦点；通过共用设置操作 interface 验证应用、取消和保存失败结果。

## 来源与交付检查

- 图标资源和半透明背景来自已验收原型，继续保留多尺寸应用版及托盘版。
- 演示：调色盘输入 → 实时拖动透明度 → 取消／应用 → 切换图标 → 重启恢复。
