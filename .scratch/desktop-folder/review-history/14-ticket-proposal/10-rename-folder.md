# 10: 重命名 Folder 并保持目录、标识和状态一致

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 04
User stories: 36, 47, 49–50

**实现内容（What to build）：** 用户从头部菜单重命名 Folder，真实内容目录同步改名；内容、稳定标识、位置及其他设置保持一致，冲突或失败有真实结果。

**阻塞关系（Blocked by）：** 04「启动正式程序、创建 Folder 并重启恢复」提供稳定标识、目录映射及状态提交。文件移入／移出和复杂布局不是重命名的必要前置。

## 验收标准

- [ ] 有效名称使真实目录和头部名称同步改变，稳定标识不变，目录中的内容不丢失。
- [ ] 同名提供保留两份编号、跳过、取消；编号后的实际目录名与展示名一致，不覆盖其他目录。
- [ ] 无效名称、目录占用／权限不足或状态保存失败返回实际结果；不把显示名称先改好而忽略目录执行失败。
- [ ] 已有目录监听在路径改变后继续反映内容；若完整内容展示尚未实施，后续读取仍使用更新后的稳定映射。
- [ ] 重启后名称／实际路径一致，外观和位置不被重置。
- [ ] 通过共用操作 interface 在真实临时目录验证成功、冲突、失败和保存异常；用户可通过头部菜单演示完整改名过程。

## 来源与交付检查

- 演示：给含文件的目录改名 → 检查真实名称及字节内容 → 重启 → 核对标识与设置。
