# 06: 多 Folder 展开、拖动和调尺寸保持不重叠

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 05
User stories: 12–26, 31–32

**实现内容（What to build）：** 用户可同时展开多个 Folder，拖动头部、调整尺寸并保存布局；碰到屏幕或其他 Folder 时沿边滑动，反向立即跟随，同时保持不重叠和列表左侧固定。

**阻塞关系（Blocked by）：** 05「展开真实内容并切换原生密度的网格和列表」提供完整展示区域及可检验的内容布局。

## 验收标准

- [ ] 多个 Folder 同时展开，头部与展示部分等宽；关闭／折叠一个不会折叠其他 Folder。
- [ ] 拖动以相邻输入的屏幕像素差移动；受阻时更新锚点，不累积无效位移；丢失鼠标捕获时结束拖动。
- [ ] 屏幕四边、折叠和展开 Folder 的四向接触下均可立即反向及沿边滑动，不穿越其他 Folder。
- [ ] 展开优先保持本头部位置，为冲突的其他 Folder 查找附近空位；空间不足则恢复原布局并取消展开。
- [ ] 折叠时调整头部宽高；展开时调整共享宽度与内容区高度，左侧位置不变；不提交会导致重叠的尺寸。
- [ ] 位置、尺寸和展开状态重启恢复；无法容纳的 Folder 保留记录及内容，提供重新恢复展示的入口。
- [ ] 布局处理不触发同步目录枚举、图标读取或状态文件写入来拖慢每次鼠标移动。
- [ ] 轨迹回放覆盖受阻后反向一像素、沿边滑动和不重叠；真实窗口边界及 WPF 内容布局检查共同验证结果。

## 来源与交付检查

- 原型已验收相邻输入锚点、切向滑动及列表零偏移；保留其回归输入和对可见结果的断言。
- 演示：展开两个 Folder → 接触四边及彼此拖动 → 调尺寸 → 重启恢复。
