# 14: 从设置控制开机自启并保持后台运行

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 04
User stories: 61–64

**实现内容（What to build）：** 用户从托盘打开设置，开启或关闭用户级开机自启，看到本机应用结果并保存；关闭设置后工具继续工作，明确退出后展示消失但内容保留。

**阻塞关系（Blocked by）：** 04「启动正式程序、创建 Folder 并重启恢复」提供正式应用身份、托盘、设置入口及用户状态。

## 验收标准

- [ ] 没有已保存的开启选择时不注册自启；开启／关闭同时更新实际用户级启动配置与保存的偏好。
- [ ] 更新失败时说明具体结果，界面不能只改变开关却伪装注册成功。
- [ ] 重启读取选择，重复切换不制造重复启动项；自启目标指向可运行的程序，并能在发布包位置安排下正常启动。
- [ ] 关闭设置窗口仍保留托盘和 Folder；明确退出释放窗口、热键和监听，内容目录仍存在。
- [ ] 通过设置操作 interface 检查保存及平台更新失败；Windows 验收使用可恢复的临时启动配置，验证实际开关效果并清理测试变化。

## 来源与交付检查

- 演示：托盘设置 → 开启／关闭 → 核对启动配置 → 关闭设置继续操作 → 托盘退出。
