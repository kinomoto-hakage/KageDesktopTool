# 12: 更换存储根目录、整体迁移并处理当场失败和取消

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 08, 11
User stories: 6–7, 55–58, 60

**实现内容（What to build）：** 用户在设置中选择新的存储根目录，看到全部内容目录迁移及进度；取消或执行失败时保留旧配置并尝试恢复，相关保留内容快捷方式跟随目标变化。

**阻塞关系（Blocked by）：** 08 的真实移动／冲突能力，以及 11 的保留目录／生成快捷方式关联，都被整体迁移直接使用。

## 上下文与范围

- 包含所有现有内容目录及已移除入口但保留内容的目录，不自动复活入口。
- 本票交付成功路径、运行期间的取消／失败恢复和持久操作记录；进程中断后的启动恢复及恢复不完整的专门交互由 13 完成。

## 验收标准

- [ ] 设置可选择新目录；先验证可用性、路径关系及冲突，相同根目录视为无变化，拒绝目录迁入自身或子目录。
- [ ] 全部清单和关联快捷方式目标完成后才切换正常根目录配置；“跳过”或部分完成不报告整体成功。
- [ ] 支持真实跨本地磁盘迁移，目标内容确认完成后再完成对应源移除；不依赖同盘重命名来冒充跨盘支持。
- [ ] 进度可见且可取消；迁移期间暂停会修改相关路径／映射的其他操作，避免并发更改迁移清单。
- [ ] 逐项记录旧／新路径、执行／恢复和快捷方式目标变化，写入中断后仍有可供 13 消费的记录。
- [ ] 当场失败或取消时停止继续迁移，保留旧配置并尝试恢复已迁移内容和快捷方式目标；未完全恢复的实际路径及状态保留，不报告成功。
- [ ] 用真实临时目录验证完整迁移与字节内容；只对指定逐项失败／取消使用可控适配器；保存失败、冲突及恢复失败均有明确结果。
- [ ] 跨盘环境不可用时明确记录该项未验证，不以同盘检查代替；本票交付的设置操作可独立演示成功和当场取消恢复。

## 来源与交付检查

- 演示：有活动及保留内容目录的工作区 → 选择新根目录 → 完整迁移 → 快捷方式仍可打开；再演示运行中取消及旧配置恢复。
