# 05: 展开真实内容并切换原生密度的网格和列表

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 04
User stories: 9–13, 27–35, 50

**实现内容（What to build）：** 用户点击头部按钮，在其正下方看到内容文件夹的实际项目，使用 Windows 图标和列表／网格查看方式，并能打开项目；其他程序改变文件后，项目和文件数自动更新。

**阻塞关系（Blocked by）：** 04「启动正式程序、创建 Folder 并重启恢复」提供正式入口、内容目录映射与持久状态。

## 上下文与范围

- 展示部分属于同一个 Folder，折叠只隐藏本 Folder 的展示部分，点击外部不自动折叠。
- 本票提供内容、选择、查看方式、打开及外部变化同步。移动内容由 08／09 交付，完整空间重排及尺寸交互由 06 交付。
- 启用展开前仍检查当前空间和不重叠约束；不以暂未实现重排为理由显示重叠窗口。

## 验收标准

- [ ] 展示真实文件、快捷方式和普通子文件夹；图标使用实际路径对应的 Windows Shell 图标及覆盖，不使用通用占位符替代。
- [ ] 头部计数为直接文件数，快捷方式计为文件；文件夹仍展示且双击使用资源管理器打开。
- [ ] 网格使用系统网格尺寸及标题字体，图标和文件名在完整等尺寸格子内居中，长名称换行／必要时省略，项间距一致。
- [ ] 列表使用本机原生小图标列表行高和字体；行宽随视口伸缩，图标／文件名左侧固定，不保存刷新时的固定行宽。
- [ ] 一键切换两种查看方式并保存；短名、长名、不同文件类型和选择高亮下均保持正确布局。
- [ ] 双击文件使用系统默认程序；枚举和图标读取失败时显示实际结果，不冻结桌面输入。
- [ ] 外部新增、删除、重命名更新项目、计数及失效图标；目录失联时保留 Folder 记录并明确说明，不自动生成空目录冒充原数据。
- [ ] 在真实 WPF 排列结果上检查格子中心、间距、行高和反复加宽／缩窄的零左侧偏移；以真实临时目录验证外部变化及打开目标。

## 来源与交付检查

- 沿用已验收的头部／下方展示结构，以及原型对 80 DIP 列表偏移的行为断言。
- 演示：在内容目录放入不同文件 → 展开 → 切换查看方式 → 外部改名 → 面板更新 → 双击打开。
