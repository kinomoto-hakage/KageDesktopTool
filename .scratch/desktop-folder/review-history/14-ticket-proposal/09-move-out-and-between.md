# 09: 移出到桌面、资源管理器或另一个 Folder

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 08
User stories: 44–49

**实现内容（What to build）：** 用户多选展示部分的项目，拖到桌面空白处、资源管理器目录或另一个 Folder，实际移动并得到一致的内容更新和结果。

**阻塞关系（Blocked by）：** 08「将真实内容批量移入 Folder 并处理同名冲突」提供实际移动、同名策略及逐项结果，作为各方向移动的共用行为。

## 验收标准

- [ ] 拖到桌面空白处时，目标是 Windows 当前用户的实际桌面目录，兼容目录重定向，不拼接固定用户名路径。
- [ ] 能拖到资源管理器中的明确目标，以及其他 Folder；支持多选文件、快捷方式和普通子文件夹。
- [ ] 原生拖放双方只执行一次移动；取消、部分完成或接收方失败时，不凭全局效果标志删除所有源项目或伪造目标路径。
- [ ] 延续保留两份、跳过、取消及逐项结果；移动后两边的实际内容、计数和展示一致。
- [ ] 快捷方式只移动自身；同一目录、无效目标、占用／权限失败及跨本地磁盘有正确结果。
- [ ] 临时目录检查路径与字节内容；真实桌面／资源管理器会话验证多选拖出、取消及 Folder 间移动。

## 来源与交付检查

- 演示：在两个 Folder 间移动 → 移到实际桌面 → 移到资源管理器目标 → 检查真实结果。
