# 11: 删除 Folder 时保留快捷方式或整体进入回收站

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 04
User stories: 51–54

**实现内容（What to build）：** 用户删除桌面 Folder 时选择保留内容或一同删除。保留时在实际桌面创建指向原内容目录的快捷方式；一同删除时完整内容目录进入回收站。

**阻塞关系（Blocked by）：** 04「启动正式程序、创建 Folder 并重启恢复」提供真实目录、展示及状态映射。移入行为并不阻塞删除，可用外部写入的目录内容独立验收。

## 验收标准

- [ ] 用户明确选择两种删除方式或取消，文件效果与所选方式一致。
- [ ] 保留内容时目录及字节内容不移动到桌面；在 Windows 实际桌面成功创建对应快捷方式后，才移除工具的展示。
- [ ] 桌面快捷方式同名时遵循编号、跳过、取消；创建失败或跳过导致未完成时，不能丢掉原可操作入口。
- [ ] 保存保留目录与工具生成快捷方式的最小关联，以便 12 迁移目标；重启不自动复活已移除的入口。
- [ ] 一同删除确认整个内容目录实际进回收站后再移除活动映射；取消或不能回收时不降级为永久删除。
- [ ] 删除、快捷方式创建与状态提交失败可区分，保留实际路径和可恢复状态。
- [ ] 用隔离目录及可替换的桌面目的地检查文件与快捷方式目标；Windows 原生集成检查仅回收临时夹具，避免用假适配器替代全部回收效果。

## 来源与交付检查

- 演示：两个含文件 Folder 分别保留内容／一同删除 → 打开快捷方式／检查回收站 → 重启核对入口状态。
