# 15: 显示桌面和 Explorer 重启后恢复可操作的 Folder

Type: implementation
Status: superseded-draft
Spec: ../../spec.md
Blocked by: 06, 09
User stories: 62, 65–66, 68–69

**实现内容（What to build）：** 用户使用“显示桌面”或经历 Explorer 重启后，Folder、托盘、输入和真实拖放仍可工作；宿主不可用时能从托盘定位实际内容并知道展示状态。

**阻塞关系（Blocked by）：** 06 提供完整可展开／移动／缩放的窗口，09 提供桌面及资源管理器真实双向拖放，才能验收恢复后的完整操作能力。

## 验收标准

- [ ] 人工 `Win+D` 进入／退出后，头部与展示部分实际可见且可以点击、拖动、缩放及操作内容，不仅检查窗口父关系。
- [ ] 普通应用覆盖、焦点变化及设置窗口显示符合桌面整理体验，不让 Folder 无故覆盖正常应用。
- [ ] Explorer 重启后恢复托盘、桌面挂接及真实拖放能力，不产生重复窗口、重复热键或丢失活动／保留内容状态。
- [ ] 宿主不可用时保留内容和配置，说明展示不可用并可打开实际目录；恢复可用后重新挂接。
- [ ] Explorer 内部窗口细节只出现在桌面适配器中，其他模块不依赖窗口名称／层次。
- [ ] 在当前真实 Windows 会话验收透明绘制、窗口命中、文件拖放和恢复；执行时避免打断未完成文件操作，保留复现与结果记录。

## 来源与交付检查

- 原型的窗口父关系、命中及透明截图作为先例；正式验收增加完整输入和重启后真实行为。
- 演示：同时展开 Folder → `Win+D` → 文件往返 → Explorer 重启 → 再次完成相同操作。
