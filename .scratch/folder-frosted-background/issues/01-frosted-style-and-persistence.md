**实现内容（What to build）：** 用户从现有“样式…”窗口为单个 Folder 启用毛玻璃，看到当前真实桌面背景的实时模糊，文字和图标保持清晰。颜色、透明度和开关一起预览、应用、取消并在重启后恢复；旧配置与新建 Folder 默认关闭，无法提供效果时显示原背景及原因。

**阻塞关系（Blocked by）：** 无，可立即领取。验证边界已获用户确认；票内先在真实桌面宿主完成隔离能力验证，再选择方案和接通正式入口。

## 上下文与边界

- 本票完整接通逐 Folder 设置、业务草稿、正式样式窗口、实际绘制、保存及验收。首先覆盖现有上方头部的折叠与展开，已启用效果不影响其他方向下原有功能；所有方向的完整视觉及生命周期验收归 02。
- 当前宿主是 Explorer 桌面子窗口。隔离验证必须观察真实后方画面、失去焦点后的持续效果、圆角和透明度极值，不能仅用顶层窗口样例或 API 返回值确定可行。
- 首版固定一种模糊强度，视觉验收后记录参数与代表性背景证据。背景需动态更新，排除 Folder 自身画面进入反馈循环。
- 复用 `IDesktopWorkspace`、`FolderRecord` 和 `AppearanceInteraction`，沿用一次保存、保存成功再发布及失效会话保护。平台细节集中在既有 Windows 桌面与运行时绘制边界。
- 本票处理能力不支持／初始化失败时的基本回退、状态提示与用户意图保存；系统限制监听、运行期间恢复和原因组合归 03。

## 验收标准

- [ ] 在当前真实桌面宿主提供可用的毛玻璃证明，记录选定方案、实际系统环境、固定强度和前置验证证据；至少一个声明支持的环境实际显示模糊。
- [ ] 现有“样式…”窗口提供“启用毛玻璃”，每个 Folder 独立设置；新建默认关闭，旧配置缺少字段时关闭且原有布局、颜色、透明度、内容与查看设置不变。
- [ ] 静态高频图案、实际桌面图标和动态背景进入当前位置的模糊结果；拖动中及落点持续更新，无自身重影或递归反馈。
- [ ] 切换应用失去焦点后效果继续显示。若平台默认材质失活后回退，所选方案仍需满足本项要求。
- [ ] 上方头部及展开展示部分背景连续，折叠只剩头部；效果限制在实际圆角内，Folder 名称、文件数、按钮、文件图标和文件名保持清晰。
- [ ] 颜色用于着色，透明度控制叠加浓淡；100% 透明仍模糊且无着色，0% 透明完全被颜色遮住，中间值连续变化。
- [ ] 关闭后恢复既有颜色与透明度；开关往返不重置这些值，不改变位置、尺寸、内容或其他 Folder。
- [ ] 开关、颜色及透明度立即预览；正式配置仍为原值，后台刷新保留有效草稿，不在正式值与预览间闪回。
- [ ] 应用一次保存完整样式，重启逐 Folder 恢复；取消、Esc 和关闭恢复打开前的有效设置，已结束会话不能再次提交。
- [ ] 保存失败保持正式状态并允许重试或取消；过期草稿不覆盖新样式，迁移／恢复锁定及显示变化保护继续有效。
- [ ] 应用草稿保留期间独立提交的布局、查看方式和内容变化，不用旧记录覆盖；实际文件路径与字节不受影响。
- [ ] 不支持或初始化失败时使用当前颜色与透明度回退，样式窗口提示“当前环境无法显示毛玻璃”；仍可保存开关意图，不能把临时不可用写成关闭。
- [ ] 通过正式业务边界及隔离真实状态文件覆盖默认、兼容、预览、取消、保存失败、重启和并发保护；正式桌面入口使用真实输入并留存视觉证据。
- [ ] 记录基础动态背景和拖动场景的性能、资源与输入表现，供 02 扩展多实例验收；原有文件打开、菜单和内容操作保持正常。
- [ ] 无法满足真实后方画面、持续效果或透明度极值时记录具体受阻证据；静态壁纸快照或始终回退不作为本票完成结果。

## 验证方法

- 业务检查复用现有外观及状态存储夹具，测试外部结果，不逐项测试内部绘制调用。
- 实际桌面使用随机隔离 Folder、真实文件、图标和变化背景，通过系统鼠标／键盘操作开关、滑块与应用／取消，比较真实截图或录屏。
- 记录未覆盖的动态壁纸、硬件和系统环境；离屏 WPF 渲染只能辅助验证前景，不能单独证明后方画面被模糊。
