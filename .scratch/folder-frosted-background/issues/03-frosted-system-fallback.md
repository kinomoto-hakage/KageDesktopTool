**实现内容（What to build）：** Windows 关闭透明效果、开启高对比度或进入省电模式，以及运行时能力不可用时，Folder 自动回到原有背景，样式窗口说明原因且保留用户启用选择；所有限制解除并可提供效果后自动恢复，预览和应用／取消继续一致。

**阻塞关系（Blocked by）：** 01 — 毛玻璃核心效果与样式保存。需要真实效果、正式设置和基本不可用回退；不依赖 02 的四向与宿主恢复扩展。

## 上下文与边界

- 本票完整覆盖系统环境获取、运行时有效状态、样式窗口反馈、用户意图保存及真实系统验证，可在已工作的上方布局独立演示。
- 区分已保存开关、当前有效草稿和运行时可用性。环境状态及暂停原因不写回为关闭，也不在条件解除后持续阻止效果。
- 复用既有 Windows 平台边界；必要抽象仅用于传入外部环境事实，不扩散系统 API 到业务层，不为每个限制建立独立业务接口。
- 02 已存在时使用其资源生命周期与四向绘制；尚未完成时不要求先扩展这些行为。

## 验收标准

- [x] 实际关闭 Windows 透明效果时暂停毛玻璃，显示当前有效颜色与透明度背景；开关保持用户选择，样式窗口显示暂停原因。
- [x] 实际开启高对比度和进入可触发的省电模式时分别执行同一暂停规则，并给出对应原因；没有真实覆盖的条件明确标为未验证。
- [x] 系统设置变化后更新已显示 Folder 及打开的样式窗口，无需用户重新切换毛玻璃开关或重启程序。
- [x] 两个以上限制叠加时保持回退，解除部分限制后继续提示剩余原因；全部解除且效果能力可用后自动恢复。
- [x] 平台在运行期间不可用或效果资源失败时回退并显示“当前环境无法显示毛玻璃”，保留用户意图；能力恢复后自动重建当前有效效果。
- [x] 失去焦点不作为暂停原因；无系统限制且能力可用时仍持续显示实时毛玻璃。
- [x] 开关本来关闭的 Folder 在任何环境变化和恢复后仍保持关闭，其他 Folder 的设置独立。
- [x] 暂停期间仍能预览颜色与透明度，并应用开关意图；应用成功后实际状态文件及程序重启保留该意图。
- [x] 编辑期间限制变化按有效草稿更新，取消、Esc 或关闭只恢复原样式；恢复后按当前环境重新计算效果，不撤销系统变化。
- [x] 预览期间后台刷新保持有效草稿，应用仍一次保存完整样式；保存失败可重试或取消，过期会话与恢复锁定保护不被绕过。
- [x] 提示区分环境不支持与系统暂停，用户能理解已启用但未生效的原因；恢复后清除不再成立的原因。
- [x] 暂停时停止并释放不需要的效果资源，反复暂停／恢复无旧背景残留或资源持续增长，前景与正常 Folder 操作保持可用。
- [x] 确定性环境轨迹覆盖限制叠加、能力失效、草稿取消和用户关闭；通过实际 Windows 设置切换与真实桌面截图或录屏核对平台行为。
- [ ] 若本票最后完成，与 02 组合验收四向 Folder、多个 Folder 及 Explorer 重启时的暂停／恢复；宿主恢复不会绕过系统限制，条件满足后恢复当前有效样式。

## 验证方法

- 外观保存与草稿行为继续通过 `IDesktopWorkspace` 验证；运行时状态决策在既有平台边界提供确定性环境输入，测试可见结果与保存意图。
- 真正系统设置切换、后方画面模糊、实时恢复和原因提示需要真实 Windows 会话证据；模拟轨迹不能替代系统监听和绘制验收。
- 使用隔离工作区并串行执行桌面输入；真实验收临时改变的系统设置在检查结束后恢复，记录省电模式等无法实际触发的条件。
