**实现内容（What to build）：** 用户在四种头部方向、不同尺寸和多个 Folder 中得到连续、正确裁剪且随位置更新的毛玻璃。折叠／展开、DPI 与桌面宿主变化后背景继续对齐，Explorer 重启后自动恢复，原有文件操作保持正常。

**阻塞关系（Blocked by）：** 01 — 毛玻璃核心效果与样式保存。需要已接通的效果、正式开关和样式预览入口；不依赖 03 的系统限制监听。

## 上下文与边界

- 本票以真实显示效果和现有交互为完整交付，包含必要几何更新、资源管理、运行时恢复及自身验证，不单独交付未接入界面的渲染框架。
- 复用已有四向几何、物理像素锚点、DIP 尺寸及 DPI 换算，背景跟随可见边界，不引入额外自动移动。
- 覆盖多个 Folder 的独立采样与生命周期，防止状态、背景或资源错误共享。
- 环境无限制时即可独立验收四向与 Explorer 恢复。03 已存在时，同时遵守其当前暂停状态，不因宿主恢复强行开启效果。

## 验收标准

- [x] 上、下、左、右头部的折叠／展开均显示完整连续背景，交界不重复模糊、不留明显接缝，收起区域不残留效果。
- [x] 实际拖动、方向切换和头部／展示部分尺寸调整时，采样位置、覆盖区域与最终窗口边界一致；圆角外桌面像素保持原样。
- [x] 头部名称横排／竖排、文件数、按钮、文件图标和文字保持清晰；不同方向下前景内容正常命中。
- [x] 背景更新沿用当前物理坐标与目标 DPI，负坐标和缩放轨迹下不产生偏移；真实硬件验证与模拟轨迹分别记录。
- [x] 多个已启用 Folder 同时显示自己的背景，互不覆盖开关、颜色、透明度、采样区域和资源；关闭一个不影响其他 Folder。
- [x] 程序重启恢复当前设置，Explorer 重启及桌面宿主丢失时安全释放／停止旧效果，宿主恢复后在当前有效样式下重建。
- [x] 预览期间宿主重建继续显示有效草稿；取消恢复正式样式，应用与后续重启保持一致，后台刷新不切回旧背景。
- [x] 关闭、删除 Folder 和多次宿主重建无效果残留；反复操作后资源不持续增长，其他 Folder 继续正常显示。
- [x] 毛玻璃切换与恢复不改变 Folder 布局，不改动实际内容；位置拖动松手才寻找空位，其他几何操作沿用现有规则。
- [x] 列表／网格、滚动条、选中名称全文、Ctrl／Shift 多选、双击打开、原生右键菜单及文件移入移出通过真实输入回归。
- [x] 明暗背景、桌面图标、透明度极值、多个 Folder、动态背景和拖动场景留存视觉及 CPU／GPU／资源观察，桌面交互保持流畅；不填入未经测量的性能结论。
- [x] 真实硬件未覆盖的多屏、混合 DPI、拔屏及系统缩放变化明确列出，不用模拟或其他功能的历史验收代替。
- [x] 若本票最后完成，与 03 组合验收四向 Folder 在系统暂停、预览及 Explorer 重启后的回退和自动恢复；全部条件满足才恢复效果。

## 验证方法

- 通过已有业务边界核对设置、布局和内容的外部结果；采样对齐、圆角、输入和资源生命周期在真实 Windows 桌面宿主验证。
- 串行执行实际鼠标／键盘及 Explorer 生命周期检查，记录实际 HWND 边界、截图或录屏、系统环境和重复重建后的资源表现。
- 沿用现有四向输入、样式反馈与桌面恢复检查模式，确保检查操作的是正式功能入口。

## Answer

已实现并验证本票。`FolderHeader`／`FrostedBackdrop` 共享四向物理几何，100% 透明空白输入使用共用正式布局／指针／移动路径，不添加着色 alpha；背景释放、定位失败回退、OLE 所有权与宿主恢复完整接入。真实八组合、完整内容和 OLE、开启效果的 Explorer 重启及多个实例全部通过。

高对比解除后首次资源曾呈现纯黑背景，已用真实蓝→绿像素得到 red，再接入 `VisualStyle` 合并通知后的延迟资源重建得到自动 green；没有以 HWND 存在或手动重绑代替恢复证据。最终系统设置恢复为透明开启、高对比关闭、现代节能 0。

完整证据、CPU／GPU 数值、30 轮资源结果、夹具修订、复现命令和硬件边界见 [02 验证记录](../../../docs/verification/frosted-02-layout-and-recovery.md)。真实硬件只覆盖当前单屏 150%；多屏、混合 DPI、拔屏、主屏与系统缩放变化等仍未实机验证。原始证据保留于 ignored verification，集成归档为 `verification/ticket-02/`。业务完整检查与 Release 构建均通过；没有修改父规格为完成，也没有发布 Release。
