**实现内容（What to build）：** 用户可以直接双击展示部分的文件、程序、快捷方式和子目录，在图标上使用原生完整文件菜单、框选多个项目，并调整网格／列表图标尺寸与自动／手动顺序。快捷方式标签和滚动条按规格优化；这些能力共同保持现有真实文件移入移出行为。

**阻塞关系（Blocked by）：** 无，可立即开始。内容交互、图标尺寸和排序之间的原依赖均在本票内部处理。

## 上下文与范围

- 基线是用户实际双击运行的 1.0.0 发布包。已有 Shell 打开方法不能证明真实双击输入能到达该方法；旧验收注入双击事件，跳过实际点击和 Preview 输入路由。先建立准确复现，再确认根因并修复。
- 桌面 Folder 对应真实内容文件夹；所有打开、菜单和移动以项目实际路径为依据，显示名称变化不改变文件名、路径或快捷方式目标。
- 初始票据曾采用 Windows 原生传统完整菜单；2026-10-04 用户澄清后的最终菜单要求见“原地菜单要求”，以最新要求为准。同一 Folder 内拖动到新位置后自动切换自定义排序，拖到其他 Folder、桌面或 Explorer 则执行真实文件移动。
- 沿用共用 `IDesktopWorkspace` 业务检查与真实 Windows 输入验收。本票自行完成新增偏好和顺序的旧状态默认值、提交失败和重启恢复。

## 验收标准

- [x] 建立并记录真实鼠标双击复现，在基线准确观察用户症状，再验证修复。普通文件按默认关联打开、程序和快捷方式启动真实目标、子目录进入 Explorer；图像和文字区域、先选中再双击及未选中直接双击均覆盖，空白处不打开旧选择。
- [x] 图标右键调用实际对象的 Windows 原生完整菜单，支持单项和多项选择及系统／已安装程序提供的适用命令；未选项目先切换选择，已选项目保留集合。菜单结束后更新项目、计数和实际结果。
- [x] 头部和展示部分空白处继续提供 Folder 管理入口，图标菜单与 Folder 菜单正确区分。
- [x] 空白处拖动显示选框，支持不同方向、Ctrl／Shift、边缘自动滚动和释放后保留选择；阈值、鼠标捕获与图标拖动配合，不误触打开或文件移动。
- [x] 刷新后仍存在的选中项目保持选择，已删除项目移出选择；双击、右键、框选和拖动使用当前命中对象及选择集合。
- [x] `.lnk` 标签隐藏后缀，实际文件名、路径、目标和冲突检测保持正确；验证去掉本程序内快捷方式箭头的能力，保留关联／自定义图标及其他适用状态标记。若存在无法避免的限制，提交实测证据，不将未实现标为完成。
- [x] 网格和列表均提供 16／32／48／96 DIP 四档图标；DPI 缩放后图像清晰，文本、行高、格子、选框和插入标记正确，不重叠且可准确命中。
- [x] 名称使用数字自然排序；修改日期及大小支持升序／降序，使用项目本身属性。自动排序目录优先，两类分别排序；按大小时目录按名称，快捷方式按 `.lnk` 自身大小；同键和缺失元数据按规格稳定处理。
- [x] 内部重排有插入反馈，释放到新位置自动切换自定义排序；多选项目保持相对顺序，未越过阈值、取消和原位释放不改排序。重排只改变显示顺序。
- [x] 自定义顺序紧凑排列；新增项目追加、删除清理旧项目、本工具重命名保留位置；外部重命名可靠识别时保留，否则按新增处理。切回自动排序后可恢复最近手动顺序。
- [x] 查看方式、尺寸、排序键／方向及自定义顺序按 Folder 独立保存并重启恢复；保存失败恢复之前已提交值。旧状态缺字段时名称升序、无手动顺序，列表小图标、网格中图标。
- [x] 滚动条为圆角滑块，滚轮、轨道点击和滑块拖动有效，保留可命中的宽度。
- [x] 跨 Folder、桌面和 Explorer 的多选移入移出仍执行一次真实移动；冲突、取消、失败结果和项目／计数刷新符合现有行为。
- [x] 共用业务检查及真实 Windows 隔离夹具覆盖上述行为，并记录普通发布 EXE 的准确输入结果；不使用事件注入替代真实双击和拖动验收。

## 票内实施顺序

先复现并修复双击／菜单，再完成选择和快捷方式显示，随后接入图标尺寸、排序、重排与滚动条。每步保留可运行检查，最后验证这些交互配合。
