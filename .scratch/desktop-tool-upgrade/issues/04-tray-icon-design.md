- 本票交付图标资源、方案切换、真实托盘显示和自己的发布资源验证；最终完整包由 05 交付。

## 验收标准

- [x] 四套托盘方案重新优化有效图形面积，明显减少多余透明留白；提供浅色／深色任务栏及小尺寸对照预览，图形易辨认且边缘完整。
- [x] 各实际托盘尺寸和 DPI 使用适合分辨率的资源，图像不被裁切或模糊缩放；验证当前系统真实托盘效果，并说明其他环境的覆盖范围。
- [x] 默认 D，A／B／C／D 选择继续有效；保存成功后同步托盘及适用已打开窗口，重启读取原偏好，保存失败保留已提交方案。

- [x] EXE 内置图标、运行时资源、输出与发布配置匹配已确认的方案规则；完整包内需要的各分辨率资源可读取，无缺失或旧增量资源混入。
- [x] 业务检查与真实 Windows 会话核对方案切换、失败、重启和托盘恢复，记录预览及资源验证结果。

## Answer

四套托盘图标已收紧留白，16px 下有效图形为 14×14px，24px 下为 22×22px。每套提供 68 帧；默认 D、A／B／C／D 偏好和应用窗口对应关系继续保留，EXE 内置应用 D。任务栏 DPI 变化及 Explorer 恢复按实际尺寸加载，复用原托盘、菜单和控制器。

完整 63 项业务检查、Release 完整重建（0 警告／0 错误）、四套共 272 帧资源检查、真实鼠标托盘切换、真实文件锁保存故障、磁盘状态重载和实际 Explorer 重启检查通过。全新含空格目录的自包含发布包检查及真实托盘会话通过，八个 ICO 与源文件 SHA256 一致，没有旧增量资源混入。

当前真实环境为单屏 150% 浅色任务栏，使用 24px 帧。真实深色系统主题、其他 DPI、混合 DPI、多屏、切换主屏和动态系统缩放尚未实际验证；浅／深色预览和资源全尺寸加载检查不能替代这些环境的硬件验收。
