**实现内容（What to build）：** 操作完成后用户通过 Windows 通知接收结果，可在分区设置中开启或关闭提示并查看详情；设置窗口采用侧栏和功能分块，Folder 样式窗口及相关入口统一命名并调整透明度标签。

**阻塞关系（Blocked by）：** 无，可立即开始。通知能力与设置中的开关在本票内贯通。

## 上下文与范围

- 基于用户提供的三张截图：样式窗口的标签位置按图 1 调整，图 2 的既有功能按图 3 的侧栏和分区形式重组；微信的账户／聊天等功能不属于本工具。
- 通知属于 Windows 系统结果反馈，需在普通用户双击自包含 EXE 的场景验证；询问和输入继续使用交互窗口，进行中的可取消进度仍可显示。
- 关闭消息提示时结果详情与必要恢复状态仍可在设置查看。通知不可用或被系统屏蔽时不回退成完成结果弹窗，不改变实际操作结果。
- 沿用共用 `IDesktopWorkspace` 验证通知偏好、样式提交和旧状态默认值，真实 Windows 会话检查通知及界面。

## 验收标准

- [ ] 文件移入移出、新建、删除、重命名、查看设置及其他操作的纯完成结果通过 Windows 通知反馈；已有完成日志窗口自动结束，不要求用户关闭结果弹窗。
- [ ] 一批操作汇总一条通知，列出成功、跳过、取消、失败计数及必要失败摘要；详细实际路径在结果详情可查。单项成功简短呈现，通知点击查看结果或状态而不再次执行操作。
- [ ] 设置包含消息提示开关，默认开启；缺少字段的 1.0.0 状态同样开启。用户选择持久保存并重启恢复，保存失败保留原值且可查看失败原因。
- [ ] 开关关闭后不投递操作结果通知；系统屏蔽通知或投递失败时仍保留结果详情和恢复状态，不伪造业务失败或重复文件操作。
- [ ] 名称输入、同名冲突、删除方式与其他必要询问继续显示；进行中的可取消进度、失败后的恢复入口和实际结果仍正确。
- [ ] 设置标题为“Kage 桌面工具 · 设置”，采用浅色侧栏与内容区，按通用、桌面 Folder、存储、通知、恢复与状态、关于分组，间距、按钮、分隔线和滚动布局统一。
- [ ] 原有存储选择／迁移、自启、Folder 新建与管理、刷新、状态备份恢复和关联待核对目录等入口继续可用；恢复状态下的限制、实际路径和错误说明保留。
- [ ] 样式窗口标题为“Folder 样式”，正文标明当前 Folder 名称；Folder 菜单与应用设置中的入口统一为“样式…”。
- [ ] 删除“· 实时预览”文字；透明度百分比与“完全透明”端点文本以自适应布局放到滑块右侧，在实际 DPI 下无裁切、重叠或固定空格定位。
- [ ] 颜色、RGB／HEX、调色盘焦点、实时透明度预览及取消／应用行为保持；文字和文件图标不随背景变透明，样式保存失败可重试并保留已提交值。
- [ ] 长路径、异常说明和 Folder 列表可阅读，缩放／滚动后控件可命中，设置关闭后后台继续运行，托盘退出与单实例行为保持。
- [ ] 通过业务检查核对偏好／样式的提交与失败恢复；在普通发布 EXE 的真实 Windows 会话检查通知投递、点击、开关、系统关闭通知以及设置／样式的实际渲染。

## 票内实施顺序

先贯通通知、偏好与结果详情，再将开关放入分区设置并完成样式窗口调整；最后检查所有操作入口的结果反馈和既有设置能力。
