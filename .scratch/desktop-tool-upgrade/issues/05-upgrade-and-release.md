## 上下文与范围

- 功能票已自行交付完整行为、状态与必要验证；本票补全组合使用、状态升级和最终发布检查，不能用本票替代前置票的验收。
- 新增字段默认值遵循规格：通知开启、名称升序、无手动顺序，列表小图标／网格中图标；保留已有尺寸、位置、查看方式、颜色、图标方案和未完成意图。
- 保留 1.0.0 完整包作为问题基线，另行生成新的完整发布目录；新版版本号在本票中确定并统一使用。
- 沿用共用 `IDesktopWorkspace`、真实文件夹具和当前用户 Windows 会话；发布验收核对实际 EXE、资源、系统通知和真实状态。

## 验收标准

- [ ] 01—04 均标记完成且有自身验收证据；读取正式规格与各票记录，组合检查覆盖全部 11 项反馈和用户故事。
- [ ] 在隔离副本中验证 1.0.0 有效状态、备份和未完成操作升级；新增字段有正确默认值，不覆盖真实内容、稳定归属、保留内容或待恢复意图。
- [ ] 升级后重启恢复各 Folder 的视图、尺寸、自动／手动顺序、头部高度、位置、样式及应用通知／图标偏好；故障提交保留原值和可查看原因。
- [ ] 组合检查覆盖框选与菜单／打开、不同尺寸重排与跨 Folder 文件移动、自由拖动与底部展开／调高、样式保存／设置开关与操作结果通知，实际文件和状态一致。
- [ ] 既有创建、冲突、双向批量移动、改名、两种删除、自启、根迁移及失败／取消／中断恢复通过必要回归；Explorer、显示桌面、托盘恢复、单实例及 DPI 行为保持。
- [ ] 普通用户在无 SDK 依赖的完整自包含发布包内双击 EXE 正常运行；资源和通知身份／投递可用，程序位置含空格及换包升级流程验证结果明确。
- [ ] 使用新的完整目录和统一版本生成 ZIP、逐文件校验清单及 ZIP 校验值；解压后核对文件与依赖，不覆盖旧发布包。
- [ ] 更新使用说明、升级步骤和验收记录；明确关闭消息提示后的结果查看入口、旧版回退兼容结论和未实际覆盖的系统／多屏／硬件环境。
- [ ] 完成适用业务回归、真实 Windows 检查和正式 EXE 普通启动验收；留下命令、环境、结果和必要视觉证据，未运行或失败的检查如实记录。
- [ ] 对最终改动按固定基点进行规范与规格审查，处理可行动问题；以实际检查通过和完整交付作为完成条件。
