**实现内容（What to build）：** 用户按住头部可以自由拖动经过其他 Folder，松手后只将当前 Folder 放到目标附近的空位；屏幕底部展开不足时自动移动当前 Folder。头身分隔线支持独立调整头部高度，并保存最终布局。

**阻塞关系（Blocked by）：** 无，可立即开始。

## 上下文与范围

- 用户已确认释放和展开只调整当前 Folder，其余 Folder 保持位置；无可行位置则恢复原位或保持折叠并说明原因。
- 1.0.0 的路径碰撞和展开挪动其他 Folder 是旧规格要求。本票更新相关行为断言，继续保留最终不重叠、屏幕工作区、DPI 和恢复检查。
- 位置采用物理屏幕坐标，尺寸采用 DIP；头部高度已有持久化能力，本票增加独立入口并沿用 42—82 DIP 范围。
- 共用 `IDesktopWorkspace` 验证几何预览和最终提交，真实鼠标输入核对实际窗口结果；不等待其他功能票提供几何或持久化基础。

## 验收标准

- [x] 按住头部拖动时可直接经过其他 Folder，预览持续跟随鼠标，不再因其他 Folder 阻挡而需要绕行。
- [x] 松手仅调整当前 Folder，在屏幕工作区内寻找距落点最近且满足既有布局间隙的空位；其余 Folder 的位置、尺寸和展开状态不变。
- [x] 最近位置搜索优先当前显示器，必要时考虑其他可用显示器，排除任务栏和屏幕空洞；按头部锚点物理距离选取，平局按纵坐标、横坐标确定，结果稳定可复核。
- [x] 当前位置能展开时保留原位置；当前位置不足时只移动当前 Folder 到能容纳头身整体的位置，多个已展开 Folder 保持不变。
- [x] 整个工作区没有可容纳位置时，拖动恢复原位、展开保留折叠，并返回明确原因；内容和 Folder 记录保留。
- [x] 头部与展示部分之间有可识别、可命中的分隔线；按住拖动只改变头部高度，展示部分高度、共享宽度和左侧位置保持不变，整体仍可容纳且最终无重叠。
- [x] 头部高度受 42—82 DIP 范围约束；折叠／展开切换及原右下角调整尺寸与分隔线行为一致，重启恢复最终尺寸。
- [x] 鼠标移动只预览几何；正常释放提交，Esc 恢复原布局，丢失捕获按规格结束会话；保存失败恢复已提交快照，不覆盖更新后的布局或显示环境。
- [x] 覆盖占用落点、自由穿越、无空位、底部展开、边界与间隙、负坐标、显示器空洞及 DPI 轨迹；真实 Windows 窗口位置和鼠标命中与业务结果一致。
- [x] 使用真实隔离夹具记录验收结果，保留旧状态布局兼容和必要的显示恢复回归；未实际验证的硬件环境如实列出。
