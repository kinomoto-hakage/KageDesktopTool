## 问题陈述（Problem Statement）

用户实际运行 1.0.0 后发现展示部分图标双击无法打开、右键出现 Folder 菜单，缺少框选、图标尺寸和自定义排序。当前结果窗口打断操作，设置布局及托盘图标需要改善，Folder 拖动遇到其他 Folder 时被阻挡，靠近屏幕底部时不能自动寻找展开位置。

## 解决方案（Solution）

桌面 Folder 提供真实文件打开、原生对象菜单、框选、图标尺寸与排序。结果以可关闭的 Windows 通知反馈，询问操作继续使用交互窗口。样式与应用设置采用明确的分区和统一控件外观。Folder 拖动预览允许经过其他 Folder，最终放置及自动展开仅调整当前 Folder 并维持无重叠；分隔线可独立调整头部高度。

## 实现决策（Implementation Decisions）

### 文件交互

- 打开以真实项目路径为依据；物理双击的文字区域、图像区域、已选中和未选中项目都应有效。空白处双击不打开旧选择。
- 原生菜单取得实际对象或选择集合的 Shell 菜单，并执行其中命令；菜单结束后刷新内容和状态。右键未选项目先切换选择，右键已选项目保留集合。
- 用户已确认采用 Windows 原生传统完整菜单，包含系统与已安装程序提供的菜单项。
- 框选从空白处开始，选区裁剪至展示视口；无修饰键替换选择，Ctrl 修改选择，Shift 扩展选择。启动图标拖动与启动选框使用不同命中入口。
- 内容刷新通过实际项目身份协调选择；仍存在的选中项目保留选择，删除的项目移出选择集合。双击、右键、框选和拖动都以当前命中项目和当前选择为依据。
- 隐藏 `.lnk` 后缀仅影响显示标签；文件路径、操作目标和冲突检测继续使用真实名称。
- 箭头去除局限于本工具的快捷方式绘制；不写全系统覆盖设置。技术实现需保持关联／自定义图标，并验证其他状态覆盖不被无意去除。

### 查看和排序

- 网格与列表都提供小、中、大、超大四档图标，逻辑尺寸分别为 16、32、48、96 DIP。布局、文本行高、框选和插入标记随尺寸变化，避免图标放大后重叠。
- 查看方式、尺寸、排序键、排序方向、自定义顺序按 Folder 独立持久化，状态保存成功后才发布最终设置。
- 名称使用符合 Windows 浏览习惯的数字自然排序；日期按项目本身的最后修改时间；大小按项目本身的文件字节数，快捷方式使用 `.lnk` 自身属性，子目录不递归计算内容大小。
- 自动排序的子目录置于普通文件之前，两类分别排序；按大小排列时子目录按名称排列，文件按实际字节数排列。同键项目以名称和实际路径确定稳定顺序；缺失或不可读取的元数据使用稳定的缺失值分组，不伪造大小或日期。
- 内部拖动用插入标记反馈，释放到新位置后自动切换自定义排序；多选项目保持当前可见相对顺序。跨 Folder 和外部目标继续真实移动。
- 内部拖动未超过系统拖动阈值、被取消或释放到原有位置时保持原排序；顺序提交失败恢复原顺序及原排序模式并报告失败。
- 自定义排序采用紧凑顺序，不创建任意自由坐标的图标空洞。新项目默认追加到末尾；删除清理旧项目；本工具执行的重命名保留顺序。外部重命名能够可靠识别时保留原位置，无法识别时按新增处理。
- 切回自动排序保留最近手动顺序，重新选择自定义排序后可恢复；重排不移动、改名或写入内容文件。

### Folder 几何布局

- 用户已确认：拖动预览可经过其他 Folder；最终释放时只移动当前 Folder，寻找距离落点最近的可容纳位置，不挪动其余 Folder。
- 用户已确认：展开优先保留当前位置，当前位置不可用时仅移动当前 Folder。整个可用工作区无法容纳时保留折叠并提示。
- 最近位置以当前 Folder 头部锚点到目标锚点的物理像素距离衡量，平局采用固定方向规则；优先当前显示器，必要时考虑其他可用显示器，排除屏幕间空洞和任务栏占用。
- 最近位置搜索在满足屏幕工作区、当前整体尺寸和既有布局间隙的可用候选中选择；平局按屏幕纵坐标、横坐标确定顺序。同一输入和显示环境得到相同结果。
- 分隔线拖动改变头部高度，展示部分高度与共享宽度保持不变；沿用现有 42—82 DIP 范围，尺寸变化须使整体可容纳且最终不重叠。
- 鼠标移动仅预览几何；正常释放提交，Esc 取消并恢复原布局；异常丢失捕获结束会话并以最后可提交布局收尾。提交失败显示结果并恢复已提交快照。
- 上述拖动、展开规则替代 1.0.0 的路径碰撞和挪动其他 Folder 的行为；屏幕工作区、DPI 换算、最终不重叠和恢复要求继续适用。

### 通知和窗口

- Windows 消息提示开关按应用持久化，旧状态缺少字段时默认开启。
- 文件移动、新建、删除、改名、查看设置和其他操作的纯结果改为非阻塞 Windows 通知；一批操作一条汇总，包含成功、跳过、取消和失败数量，必要时引导查看详情。
- 询问和输入保留；进行中的可取消进度界面可继续显示，完成后的纯日志窗口结束。点击通知查看对应结果或状态，不再次执行操作。
- 关闭消息提示抑制结果通知，设置中的恢复状态与错误详情继续可见。Windows 屏蔽通知时不改回弹窗。
- 单项成功以简短结果通知呈现；批次汇总列出计数及必要失败摘要，详细实际路径保留在结果详情中。通知失败不改变实际操作结果，也不重复执行文件操作。
- 样式窗口标题使用“Folder 样式”，在窗口正文标明当前 Folder 名称；相关入口为“样式…”。删除冗余预览文字并以自适应布局将百分比与完全透明端点文本放到右侧。
- 设置标题为“Kage 桌面工具 · 设置”，采用浅色侧栏与内容区，功能分组为通用、桌面 Folder、存储、通知、恢复与状态、关于。按钮、间距和分隔线统一，保持长路径及滚动内容可阅读。
- 展示部分滚动条改为圆角滑块，保留拖动、鼠标滚轮和轨道点击，并提供可命中的宽度。
- 托盘图标改善小尺寸有效图形面积，兼容浅色／深色任务栏和不同 DPI。默认 D 及 A／B／C／D 选择兼容保留，各方案统一收紧留白；最终图形需提供预览。

### 业务接口和状态兼容

- 沿用共用 `IDesktopWorkspace` 作为业务行为验收边界；必要的平台能力集中在 Windows 适配器，避免 UI 绕过业务规则写状态或移动文件。
- 新增内容视图、排序、自定义顺序和通知偏好；已有头部高度字段继续使用。
- 兼容 1.0.0 有效状态与备份，明确新字段默认值；保留内容映射、稳定 Folder 标识和未完成操作意图。
- 旧状态保持已有查看方式、Folder 位置、尺寸、展开状态、颜色和图标方案；缺少新字段时通知开启、名称升序、无自定义顺序，列表默认小图标、网格默认中图标。
- 布局和偏好保存沿用原子替换与失败恢复。旧程序对新版状态的回退能力依实际格式兼容验证结果说明。

### 行为检查

- 双击先建立能在旧版实际输入路径失败的准确复现；快捷方式目标写入隔离标记，程序或默认关联应用及 Explorer 打开都核对真实结果，不能用事件注入代替物理输入。
- 原生菜单检查单项、多项、未选项目、系统命令和已安装处理器；框选检查不同方向、修饰键、边缘滚动、丢失捕获及拖动阈值。
- 排序检查数字名称、中文名称、同键稳定性、日期和大小、目录、空视图、新增删除改名、跨 Folder 移动、重启和状态提交失败。
- 布局检查穿越障碍、落点占用、无空位、底部展开、多个已展开 Folder、负坐标、显示器空洞、DPI 变化和其他 Folder 位置不变。
- 通知在普通用户无打包身份的自包含发布 EXE 验证默认开启、关闭、重启恢复、批次汇总、通知点击和系统关闭通知；仍需核对询问与恢复入口。
- 设置与样式渲染检查文字、功能分区、长路径、150% 等实际环境和 DPI 轨迹；图标提供浅色／深色任务栏小尺寸预览并检验打包资源。
- 最终执行业务回归、相应 Windows 会话检查及发布包普通启动验收；未经实际硬件验证的多屏／拔屏覆盖如实说明。
