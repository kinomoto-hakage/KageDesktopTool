**实现内容（What to build）：** 每个 Folder 可在样式窗口独立设置上、下、左、右头部和横排／竖排名称，按对应方向展开，方向手柄可正确调整尺寸。实时预览、应用、取消及重启恢复一致；优先保持头部位置，空间不足只移动当前 Folder，无合法预览则保留上一可用布局。

**阻塞关系（Blocked by）：** 无，可立即开始。现有内容展示可承载四向布局，不要求网格全文或统一选择先完成。

## 上下文与范围

- 本票完整覆盖状态扩展、业务几何、交互 UI、样式事务、升级兼容及验证，不拆成只交付 schema 或几何模块的横向任务。
- 先把现有顶部布局中的头部锚点与窗口边界统一表达，再扩展四向；所有布局、放置、显示恢复和 UI 采用相同几何，不能分别计算。
- 默认上方头部、横排名称；旧配置按既有顶部位置与尺寸解释。头部位置与名称方向独立组合，新增配置按 Folder 保存。
- 展示部分宽高在切换头部位置时保持不变；图标及内容文字不旋转。左右头部长度随展示部分高度，上下头部长度随展示部分宽度。
- 头部左上角是物理屏幕锚点，尺寸使用 DIP。下／右头部展开时窗口原点不同于头部锚点；沿用目标 DPI、工作区并集、屏幕空洞、最近空位及既有布局间隙规则。
- 外观会话扩展为包含方向和几何的有效草稿，预览不写正式状态；取消包括预览触发的自动挪位，应用提交当前有效草稿。

## 验收标准

- [ ] 从现有样式窗口可独立选择头部上、下、左、右及名称横排／竖排；四位置与两方向共八种组合均可使用，新建与旧记录默认上方／横排。
- [ ] 上、下、左、右头部分别向下、上、右、左展开展示部分；折叠时只显示头部，按钮指向展开方向，展开后指向收起方向。
- [ ] 当前位置可容纳时，展开、折叠和切换方向保持头部左上角不变；下／右头部窗口原点的变化不会导致头部跳动或鼠标命中偏移。
- [ ] 从上下切换左右及返回时，展示部分宽高保持不变，侧栏高度与展示高度一致；图标和展示文字正向，内容不因宽高交换变形。
- [ ] 上／下头部保留名称、文件数和按钮横向排列；左／右侧栏名称在上、横排文件数在下、按钮在底端，信息可见且控件可命中。
- [ ] 横排名称从左向右显示；竖排按用户可见字符从上往下正向排列，中文、英文、数字都不旋转，组合字符不被拆坏。
- [ ] 八种组合中名称不足空间时省略；真实鼠标悬停可查看完整 Folder 名称，不挤出文件数、按钮或视口。
- [ ] 左／右侧栏可独立调宽，提供可用于横排名称的有效厚度范围；不未经评估套用旧顶部高度限制。
- [ ] 分隔线在上／下布局上下拖动、左／右布局左右拖动，只调整头部厚度，展示部分宽高保持不变。
- [ ] 展示部分远离头部的外角随方向正确调整展示宽高，边缘和头部相接关系一致；调整优先保持头部锚点。
- [ ] 折叠时可以调整头部长度与厚度；长度变化同步到下次展开时的相接展示边长，不出现头部和内容边缘长度不一致。
- [ ] 四向拖动／缩放沿目标 DPI 换算真实鼠标位移；保留自由拖动预览穿越其他 Folder、释放才寻找合法落点以及取消会话的已有行为。
- [ ] 当前位置越界或与其他 Folder 冲突时，仅当前 Folder 寻找最近合法空位；其他 Folder 的位置、尺寸、展开状态与内容保持不变。
- [ ] 最近空位结果符合既有稳定规则和布局间隙；整个四向可见边界避开任务栏、显示器空洞和其他 Folder，负坐标及跨屏边界可正确计算。
- [ ] 无合法展开位置时保持原折叠状态并说明原因，不自动缩小内容、交换宽高或移动其他 Folder。
- [ ] 方向、名称排版、颜色及透明度在样式窗口实时预览；因方向或尺寸变化产生的移动只属于当前有效草稿，正式配置仍保持打开前状态。
- [ ] 切换方向或增加侧栏宽度找不到合法空位时，保留上一个可用布局并提示；该次无效修改不成为应用保存的有效设置，用户仍可选择其他设置。
- [ ] 应用一次保存当前有效样式与几何，重启逐 Folder 恢复头部位置、名称方向、尺寸及锚点，其他 Folder 不受影响。
- [ ] 取消或关闭样式窗口恢复打开前的样式、尺寸及位置，包含预览期间寻找空位产生的挪动；不留下部分已提交的方向或外观。
- [ ] 保存失败保留原正式配置并允许重试或取消；过期会话、显示变化和恢复锁定沿用既有保护，旧草稿不覆盖后来有效的状态。
- [ ] 真实旧状态缺省新增字段时能初始化、保存与重启，保留原位置、原尺寸、内容目录、查看方式、图标尺寸、排序和颜色透明度；不以空白新状态代替兼容验收。
- [ ] 同步更新领域中展示部分固定在头部下方的旧描述，继续使用头部、展示部分和内容文件夹等既有术语。
- [ ] 通过 `IDesktopWorkspace` 覆盖四向几何、草稿、应用／取消、无空间、保存失败、旧状态、显示变化及其他 Folder 不变，保持正式业务边界。
- [ ] 通过真实 Windows 输入、随机隔离文件和实际桌面窗口验证方向按钮、八种文字组合、悬停、四向缩放、样式预览／取消／重启，核对截图、实际窗口边界及命中。
- [ ] 在业务轨迹中覆盖左右／上下跨屏、负坐标、混合 DPI 和屏幕空洞；实际硬件未覆盖项明确标注，不以模拟或历史单屏通过代替真实多屏验收。
- [ ] 保持现有列表／网格、内容滚动、文件打开／移动及选择行为；若 01 或 02 已完成，同时验证四向视口中的全文裁剪／滚动、头部及外部点击清除选择。

## 实施与验证

先保持旧顶部行为可运行并统一锚点与边界，再完成四向持久化和 UI，随后接入名称排版、方向手柄与样式几何事务，最后完成无空间／失败／恢复及真实输入矩阵。适度重构置于本票内实施前段，每一步保留已有契约，不建立需要其他票迁移的公共几何框架。

本票可先于 01／02 用现有内容展示独立验收。若本票是三项中最后完成的一项，同时补齐完整名称、统一清除和样式／重启的组合检查；若其他票最后完成，则该票承担同样的组合检查。
