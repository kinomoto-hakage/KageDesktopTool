## 用户反馈与交付范围

1. 样式窗口切换头部位置后，未应用期间 Folder 约每三秒闪烁；刷新应直接显示有效草稿，并继续更新真实目录内容。
2. 下／右头部分隔线必须跟随鼠标。固定头部外缘，按实际厚度变化调整头部原点，不改变展示部分宽高。
3. 样式窗口上下方向显示头部高度（42–82 DIP），左右方向显示头部宽度（64–360 DIP），滑块右侧显示当前数值；切换方向不串改另一维度。
4. 鼠标外角及分隔线调整尺寸碰到工作区边界或其他 Folder 时，保留最后有效尺寸，不通过搜索空位挪动 Folder；反向输入立即响应。位置拖动保留释放时最近合法位置语义。
5. 用户进一步明确全部取消：展开、头部方向切换和样式滑块也只检查当前位置；空间不足保持折叠或上一个有效草稿并提示，不自动挪位。

本票按本次人工反馈修正原规格中尺寸受阻自动挪位的行为。下／右分隔线的原点变化属于固定外缘的正常厚度调整，不属于寻找空位。
