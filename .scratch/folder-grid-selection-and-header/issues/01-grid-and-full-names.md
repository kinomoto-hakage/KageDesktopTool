**实现内容（What to build）：** 用户切换小、中、大、超大网格图标后看到相应的格子和间距，未选中名称最多三行并省略；选中项完整名称在 Folder 内展开，滚动整个内容可阅读全文，不改变 Folder 尺寸或其他图标位置。展开文字与该项目拥有相同的点击、打开和原生菜单行为。

**阻塞关系（Blocked by）：** 无，可立即开始。现有本 Folder 选择与取消能力足以完成本票，不等待统一选择协调或四向头部。

## 上下文与范围

- 本票包含度量、展示、输入、滚动、相关设置兼容和自身验收，不单独发布 UI 或测试层。
- 四档沿用已有尺寸和每 Folder 查看设置；系统标题字体与 DPI 信息作为度量输入，不继续让小／中档被同一系统网格下限锁成相同布局。
- 全文展开对象为单选项，或多选中的最后点击／键盘定位的选中项。其他多选项继续最多三行；取消选择或对象变化必须移除旧全文反馈。
- 全文与内容一起滚动并受所属视口裁剪，不提供名称独立滚动框，不在 Folder 外显示，不增加 Folder 几何尺寸，不参与最近空位计算。
- 当前图标选择、双击打开、菜单、身份刷新和真实文件移动保持现有契约；跨 Folder 与外部清除触发属于 02。

## 验收标准

- [ ] 固定 Folder 尺寸，依次切换小、中、大、超大，格子宽高及图标间距有实际适配变化；小／中档不能继续共用相同的格子和间距。同档排列一致，列数按可用宽度重新计算。
- [ ] 格子优先给名称留足横向空间；短名称完整，长名称最多三行，超出使用末尾省略号；图标、文本、命中、选框及插入标记与格子对应。
- [ ] 列表视图布局保持现状；两种视图已有各自尺寸和排序设置可继续使用，实际文件名、路径、快捷方式目标不因展示调整改变。
- [ ] 单选被省略的名称展开完整文字；多选仅最后点击或键盘定位的选中项展开，其余项保留三行，旧展开对象及时恢复。
- [ ] 展开／收起不改变任何图标的格子位置和间距，不改变当前或其他 Folder 的位置、尺寸和展开状态，不调用 Folder 放置来容纳文字。
- [ ] 选中最下行的超长名称，整个内容区域的滚动范围足以读到全文末尾；文字始终留在所属展示视口内，滚出部分被裁剪，不出现在其他 Folder 或桌面区域。
- [ ] 全文可以临时遮住后续项目；展开文字的真实点击、双击和右键均归属当前项，右键仍使用正确的现有选择集合。取消后下方项目恢复可见且可命中。
- [ ] 选中时仅做必要滚动，让图标和名称开头可见；用户随后滚动不被自动拉回，操作滚轮和滚动条不取消选择。
- [ ] 取消选择或切换展开对象后保留当前有效滚动偏移；额外滚动范围收起后仅当偏移超界才回退到新末端，不跳回选中前的位置。
- [ ] 当前 Ctrl／Shift 点击、键盘定位、连选和框选继续可用；真实双击文件／快捷方式及原生菜单没有被新增文字命中或选中反馈吞掉。
- [ ] 普通刷新仍按身份保留有效选择；已取消的选择及旧全文不会重新出现，已删除项目或失效对象不会留下可操作的文字反馈。
- [ ] 现有内部重排、跨 Folder／桌面／Explorer 的拖动使用正确文件集合，真实移动效果不受全文遮挡或选择处理影响。
- [ ] 旧状态可加载，四档查看设置、排序及外观保存／重启恢复继续有效；不为完整名称或滚动反馈增加持久化选择状态，相关保存失败保持原配置。
- [ ] 通过真实隔离文件、系统鼠标和键盘输入及渲染／窗口证据覆盖四档、三行、末行全文、覆盖命中及滚动恢复；不能仅通过直接设置控件选择或注入 WPF 事件验收。
- [ ] 不同 DPI 的图像、文字和命中与实际位置一致；未实际覆盖的硬件环境明确记录，列表及现有文件操作回归完成。

## 实施与验证

先统一网格度量和命中，再完成三行及四档布局，随后接入当前全文对象、整体滚动范围与命中，最后完成取消／换项的偏移保持和真实交互回归。通过现有工作区入口验证查看设置及兼容；通过既有真实 Windows 内容输入与布局检查验证可见文字和实际操作。

实现先于票据 02 时，本票使用已有本地取消入口验收。若 02 或 03 已完成，必须同时验证外部清除能够收起全文，以及四向展示视口内的裁剪和滚动。
