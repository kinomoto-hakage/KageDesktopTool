**实现内容（What to build）：** 点击桌面非 Folder 区域、任意 Folder 头部或空白、任务栏或切换应用时，之前 Folder 的图标选择统一清除；操作另一 Folder 时只保留当前操作的选择。同 Folder 的 Ctrl／Shift 多选、滚动、当前图标原生菜单及已开始的文件拖动仍然正确工作。

**阻塞关系（Blocked by）：** 无，可立即开始。现有图标选择及输入会话即可验证本票，不等待网格全文或四向头部。

## 上下文与范围

- 统一协调选择属于应用层瞬时交互，桌面命中与前台切换属于 Windows 平台适配；不把选择写入配置，也不为检查新增公开的测试专用业务 API。
- 原生图标菜单与当前操作拥有明确归属，不能把它的临时前台变化当成切换到其他应用；点击菜单外的桌面、任务栏或其他应用则清除。
- 清除现有选择集合时同步清理陈旧连选锚点及当前全文反馈；若全文尚未实现，完成已有可见选择和锚点清理即可独立验收，后续全文观察相同选择变化。
- 普通刷新和当前滚动不是清除触发；外部检测不吞掉原始系统点击，也不能破坏已开始的真实文件拖动集合。

## 验收标准

- [ ] 在至少两个 Folder 中，通过真实点击桌面空白和桌面项目，验证所有旧 Folder 选择清除；桌面或项目仍正常收到原点击。
- [ ] 点击任意 Folder 头部，包含之前选中项所在 Folder 和另一 Folder，均清除图标选择，原头部展开／拖动等操作仍可用。
- [ ] 普通左击或右击任意 Folder 空白清除所有 Folder 的选择；空白右键仍进入原有 Folder 管理流程，不误弹图标菜单。
- [ ] 点击或右击另一 Folder 图标时先清除之前 Folder 的选择，再按当前输入处理新 Folder；Ctrl／Shift 不累积跨 Folder 选择。
- [ ] 当前 Folder 的 Ctrl 点击切换、Shift 连选及 Ctrl／Shift 框选保持原规则；清除后新的连选不复用旧锚点，不重新选中已经取消的集合。
- [ ] 点击任务栏清除选择；鼠标或键盘切换到其他应用同样清除，真实返回桌面后不会恢复旧选择。
- [ ] 操作当前 Folder 的滚动条及滚轮保留选择，不因滚动条命中、捕获或暂时焦点变化误清除。
- [ ] 在已选图标上打开并操作原生右键菜单期间保留正确选择集合；菜单取消及内部返回不误清除。点击菜单外的桌面、任务栏或其他应用按清除规则处理。
- [ ] 右击未选项目和多选项目保持现有选择语义，菜单命令操作真实对象，打开、重命名等已有交互不因前台检测误用空集合或旧集合。
- [ ] 普通内容刷新按可靠身份保留仍有效的选择，已删除项移出集合；显式清除后任何后续刷新均不能复活旧选择。
- [ ] 选择变化同时撤销属于旧选择的可见反馈；若 01 已实现，外部清除也必须收起完整名称及额外滚动范围，并沿用其有效偏移保持规则。
- [ ] 内部自定义重排及跨 Folder／桌面／Explorer 的拖动继续使用拖动开始时的正确真实文件集合；应用切换或输入检测不会在移动中途改错来源，真实移动结果可核对。
- [ ] Folder 关闭／重建、桌面宿主恢复及应用退出后，旧事件订阅或选择归属不会继续作用于失效窗口；重新显示不会恢复已清除集合。
- [ ] 使用真实 Windows 系统鼠标、修饰键、键盘应用切换、原生菜单和随机隔离文件夹完成清除／保留矩阵验收；同时核对选择、实际输入接收与文件结果，而非仅调用内部清除方法。
- [ ] 真实桌面与焦点相关验收串行执行，记录平台环境及未覆盖硬件情况，既有双击、框选、身份刷新和文件移动回归通过。

## 实施与验证

先整理选择清除和会话归属，再接入跨 Folder 操作及桌面／前台检测，最后逐项验证清除触发、保留例外和真实文件结果。沿用当前正式 Windows 输入路径及应用生命周期，避免在多个 Folder 中各自安装不同的一套外部清除规则。

本票可用原有网格独立展示。其他票已实现时，追加全文收起、四向头部点击及侧栏／内容滚动的组合检查；共享代码变更不形成额外阻塞。
