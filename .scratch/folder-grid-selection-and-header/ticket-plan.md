## 阻塞关系与边界

- **01 不依赖 02**：现有本 Folder 选择和取消入口已经可以驱动全文展开／收起；01 观察真实选择变化即可独立交付。02 后续统一清除同一选择状态，不要求 01 为其提供另一套全局选择接口。
- **02 不依赖 01**：可通过现有图标选择、连选锚点和原生菜单／拖动会话验证清除与保留规则。若完整名称功能已经存在，必须同时验证其随选择收起；该组合验证不会把尚未实现的 01 变成 02 的前置。
- **03 不依赖 01 或 02**：当前内容展示及本地选择已经存在，四向几何与样式事务可独立应用于现有内容；新增视口几何对内容布局的约束由 03 自身验证。
- 共享控件、输入及应用协调代码需要保持一致，但共享编辑位置本身不是功能阻塞。实施时协调共享变更，真实 Windows 输入验收串行运行，避免抢焦点。
- 三张票都负责自己的兼容、失败处理和验证，不另拆纯 schema、业务、UI 或测试票。当前没有必须先完成的跨仓库机械重构；适度重构在所属功能票内部先完成，并保留既有行为。
