## 问题陈述（Problem Statement）

现有桌面 Folder 可以独立启用毛玻璃，使用固定模糊效果。用户可以调整背景颜色和透明度，却无法控制后方画面的清晰或柔和程度，难以按不同桌面区域、壁纸和个人偏好调整外观。

用户希望在现有“样式…”窗口通过滑块直观调节模糊程度，同时保留独立着色、即时预览、应用保存、取消恢复和重启恢复。精细调整需要方便使用的键盘操作，并通过鼠标悬浮提示说明用法。

## 解决方案（Solution）

在“样式…”窗口的“启用毛玻璃”下方增加“模糊强度”滑块、只读的当前百分比和“恢复默认”按钮。强度使用 0–100% 的整数刻度，越大越模糊；0% 表示背景清晰，仍保留启用状态。百分比是相对效果强度，不表示背景透明度或某个固定物理像素半径。

新建 Folder 以及缺少强度字段的旧配置默认使用 50%。以当前固定毛玻璃效果作为 50% 的观感基准，在此基础上提供减弱和增强空间；实际映射及最大模糊程度通过真实桌面验证确定。

强度属于逐 Folder 的完整样式，头部和展开的展示部分统一使用同一数值。拖动滑块、键盘调整或恢复默认时立即预览，点击“应用”成功后保存；取消、Esc 或关闭窗口放弃尚未应用的修改。正式保存后重启恢复。

滑块获得焦点后，方向键每次调整 1%，Page Up／Down 每次调整 10%，Home 调至 0%，End 调至 100%。鼠标悬停在滑块上时显示以下说明：

> 单击滑块或按 Tab 将焦点移到滑块后：方向键调整 1%，Page Up／Down 调整 10%，Home 调至 0%，End 调至 100%。

关闭毛玻璃时，滑块保持可见但置灰，保留当前数值；重新开启后恢复该强度。已启用但因系统设置或环境限制暂时无法显示毛玻璃时，仍可调整和保存强度，保留暂停原因提示；条件恢复后使用最新有效值。

背景颜色与透明度继续独立控制着色。背景完全不透明时仍可调整、保存强度，只是暂时看不到模糊变化；提高透明度后显示所选强度。恢复默认仅将强度改为 50%，不重置其他样式，并参与同一预览、应用和取消事务。

## 用户故事（User Stories）

1. 作为用户，我希望在现有“样式…”窗口调节模糊强度，以便继续从熟悉的外观入口操作。
2. 作为用户，我希望强度滑块位于“启用毛玻璃”下方，以便一起找到相关设置。
3. 作为用户，我希望滑块明确命名为“模糊强度”，以便区别于背景透明度。
4. 作为用户，我希望滑块旁显示当前百分比，以便知道和比较所选强度。
5. 作为用户，我希望百分比只用于显示，以便保持界面简单。
6. 作为用户，我希望强度范围为 0–100%，以便理解调整的两端。
7. 作为用户，我希望滑块使用整数刻度，以便进行明确、可重复的调整。
8. 作为用户，我希望向较大数值调整时背景更模糊，以便直观获得更柔和的观感。
9. 作为用户，我希望向较小数值调整时背景更清晰，以便保留更多后方细节。
10. 作为用户，我希望 0% 时后方画面清晰，以便选择没有背景模糊的外观。
11. 作为用户，我希望调至 0% 后仍保留毛玻璃勾选状态，以便数值调整不会改变开关选择。
12. 作为用户，我希望 100% 对应经过实机校准的最大模糊效果，以便使用明确的强度上限。
13. 作为用户，我希望强度百分比独立于透明度，以便不会把两个设置误认为同一种效果。
14. 作为用户，我希望新建 Folder 默认强度为 50%，以便首次启用时获得合适的起点。
15. 作为已有用户，我希望旧配置缺少强度字段时按 50% 加载，以便升级后可以正常使用。
16. 作为已有用户，我希望默认 50% 以当前固定效果为观感基准，以便升级后保持熟悉的外观。
17. 作为用户，我希望默认值两侧均有调整空间，以便选择更弱或更强的效果。
18. 作为用户，我希望每个 Folder 独立保存模糊强度，以便适应不同桌面区域。
19. 作为用户，我希望调整一个 Folder 时其他 Folder 不受影响，以便逐个设置外观。
20. 作为用户，我希望同一个 Folder 的头部和展示部分使用统一强度，以便背景形成连续效果。
21. 作为用户，我希望折叠后头部继续使用所选强度，以便折叠不改变外观选择。
22. 作为用户，我希望重新展开后展示部分使用同一强度，以便无需重复调整。
23. 作为用户，我希望拖动滑块时立即在目标 Folder 上看到效果，以便保存前比较不同强度。
24. 作为用户，我希望当前百分比随调整更新，以便显示值与预览一致。
25. 作为用户，我希望预览不会提前写入正式配置，以便可以放心尝试。
26. 作为用户，我希望强度与其他样式一起应用，以便保存一份完整外观。
27. 作为用户，我希望取消后恢复修改前的强度，以便放弃本次尝试。
28. 作为用户，我希望按 Esc 同样撤销尚未应用的强度修改，以便使用熟悉的退出操作。
29. 作为用户，我希望直接关闭样式窗口同样撤销尚未应用的修改，以便不同退出方式保持一致。
30. 作为用户，我希望应用成功后重新打开窗口显示已保存强度，以便确认设置生效。
31. 作为用户，我希望程序重启后恢复每个 Folder 的已保存强度，以便无需再次设置。
32. 作为用户，我希望保存失败时原正式样式保持有效，并允许重试或取消，以便不会只保存一部分设置。
33. 作为用户，我希望后台刷新期间保持当前有效的强度预览，以便画面不会反复跳回正式值。
34. 作为用户，我希望过期的样式草稿不能覆盖后来保存的强度，以便保留最近有效选择。
35. 作为用户，我希望点击“恢复默认”将强度改为 50%，以便快速回到基准效果。
36. 作为用户，我希望恢复默认只影响模糊强度，以便保留颜色、透明度及其他样式。
37. 作为用户，我希望恢复默认立即预览但仍需应用才保存，以便继续比较或取消。
38. 作为用户，我希望取消可以撤销本次恢复默认，以便恢复到打开窗口时的已保存强度。
39. 作为用户，我希望关闭毛玻璃后仍看得到强度滑块和数值，以便知道保留的设置。
40. 作为用户，我希望关闭毛玻璃时滑块置灰，以便清楚知道当前不能调整效果。
41. 作为用户，我希望关闭毛玻璃不会重置强度，以便重新开启时恢复之前的选择。
42. 作为用户，我希望系统暂停毛玻璃时仍可调整强度，以便提前设置恢复后的外观。
43. 作为用户，我希望系统暂停期间仍可应用并保存强度，以便限制解除后自动使用新设置。
44. 作为用户，我希望暂停期间继续看到原因提示，以便理解为什么调整时没有视觉变化。
45. 作为用户，我希望限制解除后使用最新有效草稿或已保存强度，以便恢复到当前应显示的外观。
46. 作为用户，我希望暂停期间取消草稿后按当前环境恢复正式样式，以便取消不会撤销系统设置变化。
47. 作为用户，我希望多个限制同时存在时全部解除后才恢复效果，以便继续尊重系统设置。
48. 作为用户，我希望重启后仍保留暂停期间保存的强度，以便不会丢失外观意图。
49. 作为用户，我希望用 Tab 将焦点移到滑块，以便通过键盘操作强度。
50. 作为用户，我希望方向键每次调整 1%，以便进行精细调整。
51. 作为用户，我希望 Page Up／Down 每次调整 10%，以便快速比较不同强度。
52. 作为用户，我希望 Home 和 End 分别调至 0% 和 100%，以便快速到达两端。
53. 作为用户，我希望键盘调整始终限制在 0–100% 内，以便不会产生超出范围的值。
54. 作为用户，我希望鼠标悬停在滑块上显示键盘用法，以便发现精细调整方式。
55. 作为用户，我希望提示说明先单击或通过 Tab 将焦点移到滑块，以便知道按键生效的前提。
56. 作为用户，我希望鼠标和键盘调整使用相同的预览、应用及取消规则，以便不同输入方式保持一致。
57. 作为用户，我希望调整模糊强度不会改变背景颜色和透明度，以便独立控制外观。
58. 作为用户，我希望背景透明度为 100% 时仍能看到所选模糊强度，以便使用不着色的毛玻璃。
59. 作为用户，我希望背景完全不透明时仍能调整和保存强度，以便提前设定效果。
60. 作为用户，我希望提高透明度后显示先前选定的强度，以便两个设置可以独立组合。
61. 作为用户，我希望模糊作用于实际实时后方画面，以便壁纸变化和桌面图标都得到对应效果。
62. 作为用户，我希望拖动 Folder 后仍按当前位置和所选强度显示背景，以便效果不会停留在旧位置。
63. 作为用户，我希望 Folder 失去焦点后仍使用所选强度，以便桌面观感保持稳定。
64. 作为用户，我希望 Folder 自身的文字、图标和控件保持清晰，以便继续阅读和操作。
65. 作为用户，我希望四向头部、圆角及展示部分交界处继续对齐，以便调整强度不产生接缝或边界残留。
66. 作为用户，我希望调整强度不改变 Folder 位置、尺寸、内容和其他 Folder，以便外观设置不会干扰整理结果。
67. 作为用户，我希望文件打开、原生菜单、拖动和文件移入移出继续正常，以便背景效果不妨碍桌面操作。
68. 作为用户，我希望 Explorer 恢复和显示环境变化后继续使用正确强度，以便环境变化不丢失外观选择。
69. 作为用户，我希望多个 Folder 使用不同强度时仍保持桌面操作流畅，以便视觉调整不妨碍日常使用。

## 实现决策（Implementation Decisions）

### 业务模型与样式事务

- 延用 `IDesktopWorkspace` 作为工作区业务入口，使用现有 `AppearanceInteraction` 草稿事务、`DesktopWorkspace` 合并和提交过程；不为强度增加平行的保存入口。
- 在 `FolderRecord` 增加语义为 0–100 整数百分比的模糊强度设置，默认 50。确切成员命名遵循现有模型约定；新字段缺失时采用默认值，现有毛玻璃开关的默认关闭语义保持一致。
- `JsonWorkspaceStore` 负责完整保存和加载强度。超范围或类型错误按现有无效外观配置与恢复规则处理；业务修改入口拒绝无效值，不发布无效草稿。
- 强度参与有效草稿、预览合并、完整样式提交、失败重试、取消和会话结束保护。只有强度发生正式变化时，也必须阻止旧样式草稿覆盖该变化。
- 仅调整强度不触发布局改变；应用时继续保留已独立发生的布局、展开状态和内容视图变化，沿用显示环境变化、恢复锁定和迁移期间的现有保护。
- 新增设置随完整记录的复制、恢复和持久化流程保留，不改变内容文件夹及内容字节。

### 样式窗口与输入

- 由 `StyleDialog` 承载滑块、只读百分比、恢复默认和悬浮提示。滑块置于启用开关下方；数值范围 0–100，整数步进 1，大步进 10。
- 鼠标拖动与键盘输入共用同一草稿修改和预览过程。Home／End 分别到达两端；边界按键不越界，显示值和有效草稿保持一致。
- 键盘快捷操作仅在滑块获得焦点时生效；鼠标悬浮负责说明操作，不把悬浮误作键盘焦点。
- “恢复默认”设为 50 并即时预览；沿用与强度滑块相同的可编辑条件，只修改本 Folder 的强度，不修改开关和其他外观。
- 是否允许编辑取决于用户的毛玻璃启用选择，而不是当前是否有可见模糊：关闭时置灰；启用但系统暂停、平台不可用、强度为 0 或背景完全不透明时仍可编辑。
- 系统暂停和不可用原因沿用现有提示。后台刷新和限制解除时，有有效草稿则显示草稿；否则使用正式样式。取消时恢复正式样式，并按当时的系统环境决定是否显示效果。

### 实时背景与强度映射

- 当前 `FrostedBackdrop` 直接使用 `CreateHostBackdropBrush()`，未实现可变模糊参数。增加滑块本身不构成效果完成；实现前需要在真实 Explorer 桌面宿主确认可调技术路径。
- 产品合同要求 0% 为清晰后方画面，50% 以当前固定效果为基准，100% 为实机校准的最大模糊。数值升高应使背景更模糊，并提供默认值上下的有效调整空间。
- 实际模糊参数与百分比的映射不预先指定为线性半径，也不虚构当前系统效果的半径。通过固定条件的真实桌面对比校准，并记录映射与效果证据。
- 不以颜色叠加浓度、背景 alpha 或 Folder 整体透明度代替模糊强度。保持背景颜色与透明度独立；0% 强度也不能通过清除启用意图实现。
- 使用实际实时后方画面，保持 WPF 前景清晰；保留四向头部、折叠、圆角、位置和 DPI 对齐。调整背景路线时同时保留原生背景窗口的真实输入、鼠标捕获与 OLE 文件拖放语义。
- 系统暂停、平台不可用与 Explorer 恢复继续沿用现有环境事实和恢复机制，持久化的是用户的开关与强度选择，而不是一次运行中的可见效果状态。
- 本规格确认产品目标，不把现有固定效果的历史验收当成可调强度已实现的证据。若真实可行性验证不能满足零值、默认基准或增强空间，应记录具体差距并交回需求评估，不静默改为透明度或另一套默认含义。

## 测试决策（Testing Decisions）

以下测试边界已于 2026-10-16 获用户确认：复用现有业务入口验证状态与事务，复用真实 Windows 桌面检查验证视觉、输入和系统恢复。

### 最高业务测试入口

- 优先通过现有 `IDesktopWorkspace` 与其返回的 `AppearanceInteraction` 操作真实隔离工作区，观察预览快照、正式快照、实际 JSON、重建工作区后的状态和内容字节。不新增测试专用业务接口。
- 复用现有工作区 `AppearanceChecks` 中毛玻璃预览、持久化、保存故障和并发草稿的先例。受控故障存储只用于验证保存失败、重试和取消，不用于证明视觉效果。
- 覆盖新建默认 50、真实旧 JSON 缺字段默认 50、显式 0 和 100 的往返保存、非法值拒绝、多 Folder 独立、完整样式一次保存、取消、恢复默认和会话结束。
- 覆盖预览不落盘、保存失败不发布、重试成功、重启恢复、仅强度变化导致旧会话失效，以及保留独立布局／视图变更、遵守显示环境与恢复锁定规则。
- 测试外部可观察行为，不断言私有成员、内部调用顺序、窗口对象数量或某个效果图的具体实现结构。

### 真实 Windows 桌面验证

- 复用现有桌面 `AppearanceChecks`、`FrostedInputChecks`、`FrostedSystemChecks` 和相应布局、恢复检查的真实窗口与隔离夹具，通过 `DesktopCheckSession` 组织证据、输入等待、无遮挡截图和资源恢复。不另建测试专用产品接口。
- 使用真实鼠标和键盘验证滑块拖动、Tab 聚焦、方向键、大步进、Home／End、只读数值同步、“恢复默认”、悬浮提示，以及应用、取消、Esc 和关闭窗口的完整行为。
- 在相同后方图案、颜色、透明度、位置与显示缩放下比较原固定效果、0%、较弱中间值、50%、较强中间值和 100%。验证零值清晰、默认基准、强弱方向和端点差异，保存可复核的屏幕像素及视觉对比证据。
- 使用实际蓝白／绿白等高频图案和动态颜色切换证明不同有效强度均采样实时背景；确认 Folder 前景文字、图标清晰，失焦和拖动后效果仍正确。
- 覆盖透明度 100%、中间透明度和完全不透明，证明模糊与着色独立；完全不透明时仍可调整并重启恢复强度。
