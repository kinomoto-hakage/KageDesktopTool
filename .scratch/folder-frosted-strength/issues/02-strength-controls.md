# 02：键盘精细调整、恢复默认与悬浮说明

Status: ready-for-agent

Parent: Folder 毛玻璃背景模糊强度滑块规格
User-stories: 35–38、49–56

**What to build:** 用户可以用键盘精细或快速调节已有模糊强度滑块，悬停鼠标即可了解用法；“恢复默认”一键预览 50%，并与鼠标调节一样支持完整应用、取消和重启恢复。所有操作只影响当前 Folder 的强度。

**Blocked by:** 01：实时模糊强度与完整样式保存。

## 验收标准

- [ ] 用户可通过 Tab 将焦点移到强度滑块；只有滑块获得焦点后，强度调整按键才生效。鼠标悬停显示提示，不自行转移键盘焦点。
- [ ] 方向键每次调整 1%，Page Up／Down 每次调整 10%，Home 调至 0%，End 调至 100%；所有操作限制在闭区间 0–100，百分比始终只读并同步显示有效值。
- [ ] 各种键盘操作使用与鼠标相同的业务草稿、即时预览、整体保存和取消过程；重复键与端点操作不会提前落盘或修改其他 Folder。
- [ ] 在滑块上真实鼠标悬停后显示：“单击滑块或按 Tab 将焦点移到滑块后：方向键调整 1%，Page Up／Down 调整 10%，Home 调至 0%，End 调至 100%。”提示中的实际操作与实现一致。
- [ ] 显示“恢复默认”按钮；点击仅将当前 Folder 的模糊强度设为 50%，开关、颜色、透明度、头部样式、位置、内容及其他 Folder 保持用户选择。
- [ ] 恢复默认即时预览但不提前保存；应用后重新打开和重启得到 50%，取消、Esc 或关闭窗口则撤销本次恢复默认。
- [ ] 毛玻璃关闭时滑块和恢复默认遵循相同置灰规则并保留数值；重新开启后可操作。可见效果为零或背景完全不透明时，已勾选状态下的键盘调整和恢复默认仍有效。
- [ ] 恢复默认和键盘调整沿用 01 的保存失败、重试及过期草稿保护，不新增独立保存入口；重复恢复为 50% 不影响其他样式。
- [ ] 通过现有业务入口验证键盘／默认恢复产生的有效强度在预览、应用、取消和重启中的外部行为，不为 UI 控件值或内部事件顺序编写镜像测试。
- [ ] 适用 CI 通过后，在真实 Windows 样式窗口使用系统鼠标、Tab 和上述按键验证完整流程，记录真实悬浮提示与强度变化证据；事件注入或只赋控件值不能替代真实输入结论。
- [ ] 使用现有桌面会话机制保存证据并恢复临时资源；如本票最后完成，补齐下述最终组合验收。

## 实施说明

- 仅依赖 01，不依赖 03；可以先在没有系统限制的稳定桌面中独立完成输入与事务验收。
- 02、03 中最后完成的一票负责验证：键盘调节或恢复默认后的有效草稿，在系统暂停／解除、应用或取消，以及桌面重建后仍显示应有值。组合验证沿用 03 的恢复机制和已批准边界。
- 本票只扩展同一强度功能的可操作方式，不增加数值输入框、额外快捷键系统或新的默认语义。
