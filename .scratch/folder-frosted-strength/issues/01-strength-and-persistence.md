# 01：实时模糊强度与完整样式保存

Type: issue
Status: ready-for-agent
Labels: ready-for-agent
Publication: published
Published: 2026-10-16
Parent: Folder 毛玻璃背景模糊强度滑块规格
User-stories: 1–34、39–41、57–64、66–67、69

**What to build:** 用户在“样式…”窗口通过鼠标滑块，将一个桌面 Folder 的实际实时背景调为更清晰或更柔和；头部和展示部分统一使用该强度，当前百分比即时同步，设置可以预览、整体保存、取消并在重启后恢复。新建与旧配置缺省为 50%，以当前固定效果作为默认观感基准。关闭毛玻璃保留数值，颜色和透明度仍可独立调整。

**Blocked by:** None（可以立即开始）。

## 验收标准

- [ ] 先在当前真实 Explorer 桌面宿主确认可调模糊路线，覆盖清晰零值、默认基准及默认值以上的增强空间；随后接通正式窗口。API 成功、探针完成或只显示一个仍对应固定效果的滑块，均不足以完成此票。
- [ ] “启用毛玻璃”下方显示“模糊强度”滑块及只读百分比；范围为 0–100 的整数，鼠标操作不产生小数或越界值。
- [ ] 在同一后方图案、颜色、透明度、位置和缩放条件下，0% 显示清晰背景，数值增大后更模糊；50% 以原固定效果为观感基准，100% 为实机校准的最大效果，默认值上下均提供有效调整空间。
- [ ] 保留原固定效果、0%、较弱中间值、50%、较强中间值和 100% 的真实桌面对比证据，说明采用的强度映射及上限；不预先编造当前系统模糊的数值半径。
- [ ] 新建 Folder 默认强度为 50；真实旧 JSON 缺少强度字段时加载为 50，保留已有开关选择。显式保存的 0 不得被误作缺省值。
- [ ] 强度属于逐 Folder 的完整样式，默认或已保存的数值不会同步到其他 Folder。头部和展开的展示部分使用同一强度，基础折叠／展开保持该值。
- [ ] 鼠标拖动即时更新预览和数值，正式记录及磁盘状态保持原值；有效草稿在后台刷新期间保持预览。
- [ ] 应用成功后，强度与颜色、透明度及同次编辑的其他样式一起完整保存；重新打开和重建工作区后恢复同一数值及外观。
- [ ] 取消、Esc 或关闭样式窗口撤销尚未应用的强度修改；已结束会话不能继续修改或提交。不得提前写入强度后再尝试回滚。
- [ ] 保存失败保留原正式记录和可重试草稿；重试成功只发布完整有效样式。仅强度发生正式变化也会使旧样式草稿过期，不能覆盖最近保存值。
- [ ] 仅调整强度不改变位置、尺寸、内容或其他 Folder；提交保留独立发生的布局／视图变化，并沿用显示环境变化、恢复锁定和迁移保护。
- [ ] 强度通过现有 `IDesktopWorkspace`／`AppearanceInteraction` 进入业务事务及 JSON 持久化；业务入口拒绝非法范围值，错误配置遵从现有无效外观和恢复流程。
- [ ] 关闭毛玻璃时滑块可见但置灰，数值保留；重新开启后使用当前有效值。调至 0% 保留勾选状态，不能通过修改启用意图实现零值。
- [ ] 强度不修改背景颜色、不透明度或前景透明度。背景透明度 100% 时仍显示所选模糊；完全不透明时仍允许调整、应用和重启恢复强度，提高透明度后显示所选效果。
- [ ] 不可用时至少保留既有颜色与透明度回退、原因提示和用户开关／强度意图，仍允许在已勾选状态下编辑并保存；系统组合和自动恢复的完整轨迹由 03 扩展。
- [ ] 真实后方高频图案及动态蓝／绿变化能够反映到不同有效强度下的背景，拖动后使用当前位置、失焦后持续；不能用静态截图或额外着色冒充可调实时模糊。
- [ ] Folder 自身文字、图标与控件清晰，原生背景路径仍可正确命中完全透明区域；基础真实鼠标拖动、文件打开、原生菜单和 OLE 文件移入移出可用。
- [ ] 连续拖动滑块保持可操作，没有与基线相比明显的画面冻结或持续资源增长；新增或替换背景资源被正确更新和释放。
- [ ] 复用现有隔离业务外观检查，覆盖默认、旧配置、0／100 往返、逐 Folder 独立、非法值、保存失败重试、取消、过期保护、重启及内容字节不变；不新增测试专用业务接口。
- [ ] 适用 CI 通过后，通过现有真实桌面夹具与会话入口完成此票涉及的输入及像素证据；保留运行记录，完成临时窗口、鼠标和资源恢复，明确未覆盖环境。

## 实施说明

- 先做保持现有行为的最小背景层／生命周期整理，再接入可调路线和用户操作；无需独立广泛重构票。
- 当前 `CreateHostBackdropBrush()` 固定效果本身没有已接通的强度设置；具体可调实现由真实宿主证据决定，不在票据中预先承诺未验证 API 路线。
- 若路线无法满足零值、默认基准或增强空间，记录差距并返回需求评估；不能静默更换已确认产品语义，也不能据此标记本票完成。
