**What to build:** 用户在系统暂停或环境不可用时仍可调整并保存已启用毛玻璃的强度；限制解除后，自动使用当前有效草稿或正式样式恢复实际效果。Explorer 重建、显示环境变化、四向布局及多个不同强度的 Folder 均保持各自正确外观和桌面操作。

**Blocked by:** 01：实时模糊强度与完整样式保存。

## 验收标准

- [x] Windows 关闭透明效果、开启高对比度、进入省电模式或平台不可用时，沿用现有回退背景与原因提示；保留启用选择和强度，不把暂时不可见写成关闭或重置值。
- [x] 已勾选但暂停／不可用时仍可通过正式滑块调整、预览数值和应用强度；没有实际视觉变化时保留原因提示，不因 `FrostedVisible` 为 false 就禁用强度编辑。
- [x] 暂停期间保存成功后，限制解除自动使用最新正式强度；所有同时存在的限制均解除后才恢复。重启时仍有限制则保留最新值并继续尊重限制，条件满足后自动恢复。
- [x] 有有效草稿时，限制解除和后台刷新使用草稿强度；取消、Esc 或关闭窗口后使用正式强度，并按当前系统环境决定可见效果。取消不能撤销系统设置变化。
- [x] 预览期间发生保存失败、外部正式强度变化或草稿失效时，恢复流程遵守现有事务保护，不能复活过期草稿或覆盖后来有效样式。
- [x] 用户本来关闭毛玻璃时，环境恢复不自动启用；重新打开毛玻璃使用保留的强度。强度 0% 与关闭状态的保存语义仍有区别。
- [x] Explorer 实际重启并重新获得桌面宿主后，每个 Folder 使用应有的强度重建背景；覆盖正式样式恢复及现有规则允许保留的有效预览，不使用旧宿主资源或默认 50% 替换已保存值。
- [x] 上、下、左、右头部及横／竖名称场景中，头部和展示部分使用统一强度；折叠、展开、拖动与调整尺寸后圆角边界、接缝和背景采样继续对齐。
- [x] 显示环境或 DPI 变化后，强度意图保留且采样与几何正确；按现有草稿失效规则处理旧会话。业务检查覆盖虚拟显示边界，真实多屏／混合 DPI 等未实测场景明确记录为限制。
- [x] 多个 Folder 同时使用不同强度时互不串值，关闭或重建一个实例不会重置其他实例；反复调整、暂停、恢复及销毁后资源释放正常，桌面仍可操作。
- [x] 恢复后通过实际蓝／绿背景变化和不同强度对比取得屏幕像素证据，证明恢复的是实时背景与对应效果，不能仅依赖记录值、对象存活或 API 返回成功。
- [x] 在完全透明着色、0%／中间／100% 强度及恢复后的代表性场景中，真实透明区域点击、Folder 拖动、文件打开、原生菜单和 OLE 文件移入移出正常；内容字节、几何及其他样式按各自用户操作保持一致。
- [x] 通过现有业务入口和隔离 JSON 验证暂停期间保存、逐 Folder 值保持、正式／草稿选择与重启语义；通过现有环境事实入口覆盖确定性组合，不新增测试专用产品接口。
- [x] 适用 CI 通过后，串行完成真实 Windows 系统设置、Explorer 和输入检查；记录采用的包与运行证据，恢复系统设置、鼠标和临时资源。受控事实注入不得替代真实系统状态变化的验收结论。
